오늘 암기하고 정리할 파이토치 및 머신러닝 필수 영단어와 약어 10선입니다.

### 1. MSE (Mean Squared Error)
* **약어 풀이**: Mean Squared Error
* **한 줄 뜻**: 평균제곱오차
* **코딩 사용 이유**: 모델의 예측값($\hat{y}$)과 실제 정답($y$) 사이의 차이를 제곱하여 평균을 내는 회귀(Regression) 문제의 대표적인 손실 함수입니다. 오차가 커질수록 제곱으로 인해 손실 값이 기하급수적으로 늘어나므로, 오차가 큰 예측에 더 강한 감점을 주어 정밀한 회귀 모델을 학습시킬 때 필수적으로 사용됩니다.

### 2. SGD (Stochastic Gradient Descent)
* **약어 풀이**: Stochastic Gradient Descent
* **한 줄 뜻**: 확률적 경사하강법
* **코딩 사용 이유**: 전체 데이터셋을 한 번에 계산하지 않고 무작위로 추출한 미니배치(Mini-batch) 단위로 기울기(Gradient)를 구하여 가중치(Weight)를 갱신하는 최적화 알고리즘입니다. 계산 복잡도와 메모리 사용량을 획기적으로 줄여주며, 극소점(Local Minima)에 빠지는 문제를 방지하여 딥러닝 모델 학습의 기초가 됩니다.

### 3. MLP (Multi-Layer Perceptron)
* **약어 풀이**: Multi-Layer Perceptron
* **한 줄 뜻**: 다층 퍼셉트론
* **코딩 사용 이유**: 입력층(Input Layer)과 출력층(Output Layer) 사이에 하나 이상의 은닉층(Hidden Layer)을 배치한 가장 기본적인 인공신경망 구조입니다. 비선형 활성화 함수(Activation Function)와 결합하여 단순 선형 회귀로 해결할 수 없는 복잡한 데이터 간의 상관관계와 패턴을 학습할 때 구조적 기반으로 쓰입니다.

### 4. ReLU (Rectified Linear Unit)
* **약어 풀이**: Rectified Linear Unit
* **한 줄 뜻**: 정류 선형 유닛
* **코딩 사용 이유**: 입력값이 0 이하일 때는 0을 출력하고, 0을 초과할 때는 입력값을 그대로 출력하는 활성화 함수입니다. 연산 속도가 매우 빠르고, 깊은 신경망을 학습시킬 때 미분값이 사라지는 기울기 소멸 문제(Vanishing Gradient Problem)를 방지해 주므로 은닉층의 기본 활성화 함수로 널리 채택됩니다.

### 5. CNN (Convolutional Neural Network)
* **약어 풀이**: Convolutional Neural Network
* **한 줄 뜻**: 합성곱 신경망
* **코딩 사용 이유**: 2차원 필터(Filter/Kernel)를 이미지 슬라이딩하며 공간적 특징(Spatial Features)을 추출하는 딥러닝 아키텍처입니다. 격자 형태의 데이터에서 위치 간 관계와 부분 특징(선, 면, 질감 등)을 효과적으로 파악할 수 있어 컴퓨터 비전 및 이미지 처리 과제에서 필수적으로 활용됩니다.

### 6. Tensor (텐서)
* **한 줄 뜻**: 다차원 배열 객체
* **코딩 사용 이유**: 넘파이(NumPy)의 `ndarray`와 유사하지만, GPU나 NPU 등 하드웨어 가속기에서 병렬 행렬 연산이 가능하고 자동 미분(Autograd) 기능을 지원하는 파이토치의 핵심 데이터 구조입니다. 모델의 입력, 출력, 파라미터 등 모든 데이터 흐름의 기본 단위로 동작합니다.

### 7. Loss (손실 / 손실값)
* **한 줄 뜻**: 예측 오차 수치
* **코딩 사용 이유**: 현재 상태의 모델이 낸 예측값과 실제 정답이 얼마나 다른지를 하나의 정량적인 숫자로 표현한 값입니다. 이 손실 값이 0에 가까워질수록 모델의 성능이 뛰어남을 의미하며, 역전파(Backpropagation) 과정에서 기울기를 계산하는 출발점이 됩니다.

### 8. Gradient (기울기 / 경사)
* **한 줄 뜻**: 파라미터 변화율
* **코딩 사용 이유**: 각 파라미터(가중치와 편향)를 아주 조금 변경했을 때 손실(Loss) 값이 어느 방향으로 얼마나 변하는지를 나타내는 다변수 미분값 벡터입니다. 기울기의 반대 방향으로 파라미터를 이동시킴으로써 손실을 최소화하는 경사하강법 계산의 핵심 요소입니다.

### 9. Epoch (에폭)
* **한 줄 뜻**: 전체 데이터 1회 학습 단위
* **코딩 사용 이유**: 훈련 데이터셋 전체가 모델을 통해 순전파(Forward) 및 역전파(Backward)를 거쳐 파라미터 갱신에 한 번 완전히 사용된 상태를 뜻합니다. 에폭 횟수를 조절하여 모델의 학습 부족(Underfitting)이나 과도한 학습(Overfitting)을 제어합니다.

### 10. Batch (배치 / 묶음)
* **한 줄 뜻**: 1회 학습용 데이터 묶음
* **코딩 사용 이유**: 메모리 한계로 인해 전체 데이터를 한 번에 모델에 투입할 수 없으므로, 데이터를 일정한 수량(예: 32, 64, 128개)으로 나누어 공급하는 데이터 단위입니다. 배치 단위로 파라미터 기울기를 계산하고 갱신을 진행하여 학습의 안정성을 높입니다.
