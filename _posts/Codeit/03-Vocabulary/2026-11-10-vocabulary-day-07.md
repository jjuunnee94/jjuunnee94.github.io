### 61. Exception (예외 / 오류)
- **한 줄 뜻**: 프로그램 실행 중 발생하는 예기치 못한 비정상적 오류 상태
- **코딩 사용 이유**: 잘못된 입력이나 파일 부재 등으로 프로그램 전체가 멈춰버리는 튕김 현상을 방지하고자 다룹니다.

### 62. Try (시도하다)
- **한 줄 뜻**: 오류가 발생할 가능성이 있는 코드 구역을 감싸는 블록
- **코딩 사용 이유**: 안심하고 코드를 테스트해 보고, 중간에 에러가 터져도 잡아서 처리할 수 있도록 시도 구역을 정합니다.

### 63. Except (예외 처리하다)
- **한 줄 뜻**: `try` 블록에서 에러가 났을 때 실행될 비상 대처 코드 구역
- **코딩 사용 이유**: 에러가 발생해도 프로그램을 강제 종료하지 않고 안내 문구를 띄우거나 안전하게 우회 처리합니다.

### 64. Raise (오류를 발생시키다)
- **한 줄 뜻**: 사용자가 인위적으로 에러를 일으키도록 만드는 키워드
- **코딩 사용 이유**: 잘못된 데이터 입력 시 스스로 예외를 터뜨려 후속 심각한 로직 에러를 미리 차단합니다.

### 65. Finally (마침내 / 무조건 실행)
- **한 줄 뜻**: 에러 발생 여부와 상관없이 무조건 마지막에 실행되는 블록
- **코딩 사용 이유**: 파일 닫기(`close`), DB 연결 해제 등 에러가 나든 안 나든 반드시 마쳐야 하는 정리 작업을 처리합니다.

### 66. Import (불러오기)
- **한 줄 뜻**: 외부 모듈이나 라이브러리 코드를 현재 파일로 가져오는 키워드
- **코딩 사용 이유**: 남이 이미 잘 만들어둔 수학, 전처리, 딥러닝 등의 모듈 기능(`import math`)을 즉시 이용하기 위해 사용합니다.

### 67. Module (모듈)
- **한 줄 뜻**: 변수, 함수, 클래스들을 묶어놓은 하나의 파이썬 파일(`.py`)
- **코딩 사용 이유**: 코드가 너무 길어질 때 기능별로 파일로 나누어 관리하고 필요할 때 끌어다 씁니다.

### 68. Package (패키지)
- **한 줄 뜻**: 여러 모듈 파일들을 폴더 구조로 묶어놓은 집합체
- **코딩 사용 이유**: 대규모 프로젝트에서 관련 모듈들을 계층적 폴더로 체계화하여 관리합니다.

### 69. Library (라이브러리)
- **한 줄 뜻**: 유용한 모듈과 패키지들을 모아둔 종합 도구 모음집
- **코딩 사용 이유**: 복잡한 머신러닝, 시각화 기능 등을 도구 상자처럼 편리하게 가져다 쓰기 위한 외부 코드 집합입니다.

### 70. Alias (별칭 / `as`)
- **한 줄 뜻**: 모듈이나 라이브러리 이름을 축약해서 다루는 별명 (`import pandas as pd`)
- **코딩 사용 이유**: 긴 모듈 이름을 짧은 별칭으로 축약해 코드 작성 시 긴 이름을 계속 치는 번거로움을 줄입니다.
