### 51. Class (클래스)
- **한 줄 뜻**: 객체를 만들어내기 위한 설계도 (틀)
- **코딩 사용 이유**: 관련 변수와 함수를 하나로 묶어 복잡한 프로그램을 체계적으로 설계하고 객체를 무한히 생성하게 돕습니다.

### 52. Object (객체)
- **한 줄 뜻**: 클래스 설계도에 의해 실제로 메모리에 생성된 실체
- **코딩 사용 이유**: 프로그램 내부에서 독립된 상태 데이터와 동작을 가지고 실제로 일을 처리하는 기본 단위가 됩니다.

### 53. Instance (인스턴스)
- **한 줄 뜻**: 특정 클래스로부터 구체적으로 실체화된 객체
- **코딩 사용 이유**: "붕어빵틀(클래스)로 구워낸 붕어빵 하나(인스턴스)"처럼 구체적인 데이터 독립체를 가리킬 때 씁니다.

### 54. Method (메서드)
- **한 줄 뜻**: 클래스 내부에 정의되어 객체가 행하는 전용 함수
- **코딩 사용 이유**: 객체가 가진 내부 상태 데이터를 조회하거나 수정하는 동작을 수행하도록 전용 기능을 부여합니다.

### 55. Attribute (속성 / 변수)
- **한 줄 뜻**: 객체가 가질 수 있는 고유한 상태 정보나 변수
- **코딩 사용 이유**: 객체의 특징(이름, 나이, 색상 등)을 저장하여 개별 객체마다 서로 다른 상태 값을 유지하게 합니다.

### 56. Self (자신 참조 변수)
- **한 줄 뜻**: 메서드 안에서 객체 자기 자신을 가리키는 첫 번째 매개변수
- **코딩 사용 이유**: 객체 내부의 속성(`self.name`)이나 다른 메서드에 인스턴스 스스로가 접근할 수 있도록 주소를 전달합니다.

### 57. Constructor (생성자 / `__init__`)
- **한 줄 뜻**: 객체가 처음 만들어질 때 자동으로 제일 먼저 실행되는 초기화 메서드
- **코딩 사용 이유**: 인스턴스 생성 순간 필수 속성값들을 부여하고 초기 세팅 작업을 완료하기 위해 필수 사용합니다.

### 58. Inherit (상속하다)
- **한 줄 뜻**: 부모 클래스의 기능을 자식 클래스가 그대로 물려받는 성질
- **코딩 사용 이유**: 이미 만들어둔 코드 속성과 메서드를 그대로 물려받고 필요한 기능만 추가/수정하여 중복 작성을 줄입니다.

### 59. Override (재정의하다)
- **한 줄 뜻**: 부모에게 상속받은 메서드를 자식 클래스에서 덮어써서 커스텀 작성하는 것
- **코딩 사용 이유**: 부모의 기본 동작 대신 자식 객체만의 특수한 동작이 필요할 때 같은 이름으로 기능을 재설계합니다.

### 60. Encapsulation (캡슐화)
- **한 줄 뜻**: 중요한 속성 데이터를 외부 접근으로부터 보호하고 하나로 묶는 원리
- **코딩 사용 이유**: 외부에서 함부로 객체 내부 데이터를 조작해 발생하는 에러를 방지하고 사용법을 단순화합니다.
