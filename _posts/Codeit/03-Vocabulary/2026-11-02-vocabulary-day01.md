### 1. Variable (변수)
- **한 줄 뜻**: 데이터를 저장하는 메모리 공간의 이름
- **코딩 사용 이유**: 숫자나 문자열 같은 데이터를 변수에 담아두어야 코드 실행 중에 필요할 때마다 이름($x$, $y$)을 불러 재사용할 수 있습니다.

### 2. Print (출력하다)
- **한 줄 뜻**: 화면에 결과나 문자열을 표시하는 함수
- **코딩 사용 이유**: 코드의 실행 결과나 변수에 들어있는 값을 콘솔 화면에 시각적으로 확인하기 위해 가장 기본적으로 사용합니다.

### 3. String (문자열)
- **한 줄 뜻**: 따옴표로 감싸진 텍스트 데이터 타입
- **코딩 사용 이유**: 사람의 이름, 글자, 문장 등의 텍스트 정보를 컴퓨터 내에서 다루고 연산하기 위해 지정하는 데이터 형태입니다.

### 4. Integer (정수)
- **한 줄 뜻**: 소수점이 없는 양수, 음수, 0의 데이터 타입
- **코딩 사용 이유**: 횟수를 세거나 인덱스(순서)를 지정하는 등 분수나 소수가 필요 없는 순수한 정수($1, 2, -5$)를 표현할 때 쓰입니다.

### 5. Float (부동소수점 / 실수)
- **한 줄 뜻**: 소수점이 포함된 숫자 데이터 타입
- **코딩 사용 이유**: 측정값, 확률, 가중치 등 정확한 소수점($3.14, 0.05$) 이하 계산이 필요한 숫자 데이터를 처리할 때 쓰입니다.

### 6. Assign (할당하다 / 대입하다)
- **한 줄 뜻**: 변수에 값을 지정하여 저장하는 동작
- **코딩 사용 이유**: 기호 `=`를 사용해 오른쪽에 있는 데이터 값을 왼쪽 변수 공간에 대입하여 기억시키는 기본 연산입니다.

### 7. Input (입력)
- **한 줄 뜻**: 외부나 사용자로부터 데이터를 받아오는 기능
- **코딩 사용 이유**: 키보드 입력이나 파일 형태로 들어오는 외부 데이터를 프로그램 내부로 전달받아 처리하기 위해 사용합니다.

### 8. Comment (주석)
- **한 줄 뜻**: 실행되지 않는 코드 설명글
- **코딩 사용 이유**: 숍 기호(`#`) 등을 사용해 코드를 설명하거나 잠시 실행을 멈추어 타인 및 미래의 자신이 코드를 쉽게 이해하도록 돕습니다.

### 9. Type (타입 / 형)
- **한 줄 뜻**: 데이터의 종류와 성격
- **코딩 사용 이유**: 컴퓨터가 이 값이 문자(str)인지 숫자(int, float)인지 구분하여 올바른 덧셈이나 문자열 연결 연산을 수행하게 합니다.

### 10. Syntax (문법)
- **한 줄 뜻**: 프로그래밍 언어가 정해둔 작성 규칙
- **코딩 사용 이유**: 괄호나 띄어쓰기 등 언어별 작성 규칙을 지켜야 컴퓨터가 코드를 제대로 해석하여 에러 없이 실행합니다.
