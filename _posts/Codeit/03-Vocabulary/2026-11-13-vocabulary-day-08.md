### 71. Scope (변수 유효 범위)
- **한 줄 뜻**: 변수가 접근 가능하고 살아있는 영역
- **코딩 사용 이유**: 함수 안에서 만든 변수가 바깥 변수와 충돌하지 않고 지정된 영역 내에서만 안전하게 쓰이도록 제한합니다.

### 72. Global (전역 변수)
- **한 줄 뜻**: 파일 전체 어디서나 접근 가능한 바깥 변수
- **코딩 사용 이유**: 프로그램 전반에 걸쳐 공통으로 쓰이는 설정값이나 상수 상태를 공유할 때 활용합니다.

### 73. Local (지역 변수)
- **한 줄 뜻**: 특정 함수 내부에서만 잠깐 쓰이고 사라지는 변수
- **코딩 사용 이유**: 함수 실행 동안만 계산용으로 사용하고 끝나면 메모리에서 지워 독립성을 유지합니다.

### 74. Lambda (람다 / 무명 함수)
- **한 줄 뜻**: 이름 없이 한 줄로 간단하게 정의하는 이름 없는 소형 함수
- **코딩 사용 이유**: 일회성으로 간단한 계산 함수가 필요할 때 `def` 선언 없이 즉석에서 짧게 작성해 효율을 높입니다.

### 75. Comprehension (컴프리헨션 / 한 줄 생성)
- **한 줄 뜻**: 리스트나 딕셔너리를 반복문과 조건을 써서 한 줄로 생성하는 문법
- **코딩 사용 이유**: 여러 줄의 `for` 반복문 코드를 한 줄로 압축해 가독성을 높이고 빠르게 리스트를 만듭니다.

### 76. Map (매핑 함수)
- **한 줄 뜻**: 데이터 목록의 모든 요소에 지정한 함수를 일괄 적용하는 기능
- **코딩 사용 이유**: 리스트 전체 요소의 형 변환(`map(int, list)`)이나 일괄 연산을 반복문 없이 한꺼번에 처리합니다.

### 77. Filter (걸러내기 함수)
- **한 줄 뜻**: 데이터 목록 중 조건을 만족하는 참(`True`) 항목만 추출하는 함수
- **코딩 사용 이유**: 리스트 요소 중 양수만 뽑아내는 등 특정 조건에 맞는 데이터만 손쉽게 필터링합니다.

### 78. Zip (압축 / 묶기)
- **한 줄 뜻**: 여러 개의 리스트 항목을 같은 순서끼리 쌍으로 묶어주는 함수
- **코딩 사용 이유**: 이름 리스트와 점수 리스트의 같은 위치 항목들을 한데 짝지어 다룰 때 유용하게 쓰입니다.

### 79. Enumerate (열거하다)
- **한 줄 뜻**: 리스트를 순회할 때 인덱스 번호와 요소 값을 동시에 꺼내주는 함수
- **코딩 사용 이유**: `for i, val in enumerate(list)`처럼 순서 번호와 실제 값을 함께 써야 할 때 쓰입니다.

### 80. Generator (제너레이터)
- **한 줄 뜻**: 데이터를 한 번에 메모리에 올리지 않고 필요할 때마다 하나씩 생성하는 객체
- **코딩 사용 이유**: 엄청나게 큰 용량의 데이터를 다룰 때 메모리 부족 터짐 현상을 방지해 줍니다.
