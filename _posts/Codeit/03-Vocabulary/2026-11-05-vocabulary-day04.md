### 31. Dictionary (딕셔너리 / 사전)
- **한 줄 뜻**: 키(`Key`)와 값(`Value`) 쌍으로 데이터를 관리하는 중괄호(`{}`) 자료구조
- **코딩 사용 이유**: 이름-나이, 학번-성적처럼 대응되는 데이터를 빠르게 검색하고 다루기 위해 쓰입니다.

### 32. Key (키)
- **한 줄 뜻**: 딕셔너리에서 데이터를 찾기 위한 고유한 식별자
- **코딩 사용 이유**: 리스트의 숫자 인덱스 대신 문자열 등 사용자가 지정한 키 이름으로 데이터를 직관적으로 꺼냅니다.

### 33. Value (값)
- **한 줄 뜻**: 딕셔너리의 키와 연결된 실제 데이터 내용
- **코딩 사용 이유**: 키를 호출했을 때 대응되어 돌아오는 실제 값(숫자, 문자, 리스트 등)입니다.

### 34. Tuple (튜플)
- **한 줄 뜻**: 한번 생성되면 내부 요소를 절대 바꿀 수 없는 소괄호(`()`) 자료구조
- **코딩 사용 이유**: 프로그램 실행 중 변하지 않아야 하는 좌표, 설정 데이터의 안전성을 보장하기 위해 씁니다.

### 35. Set (집합)
- **한 줄 뜻**: 순서 상관없이 중복을 삭제하는 중괄호(`{}`) 자료구조
- **코딩 사용 이유**: 데이터 목록에서 중복 요소를 제거하거나 교집합, 합집합 등 수학적 집합 연산을 할 때 쓰입니다.

### 36. Append (덧붙이다 / 추가하다)
- **한 줄 뜻**: 리스트의 맨 끝에 새로운 항목을 하나 추가하는 메서드
- **코딩 사용 이유**: 기존 리스트 목록에 새로운 데이터($x$)를 계속해서 뒤로 쌓아 나갈 때 필수적으로 사용합니다.

### 37. Pop (꺼내다 / 삭제하다)
- **한 줄 뜻**: 지정한 위치의 항목을 꺼내면서 리스트에서 제거하는 메서드
- **코딩 사용 이유**: 처리 완료된 항목을 데이터를 사용하는 동시에 목록에서 없앨 때 활용합니다.

### 38. Len (Length / 길이)
- **한 줄 뜻**: 문자열이나 리스트 내부 요소 전체 개수를 구해주는 함수
- **코딩 사용 이유**: 데이터가 총 몇 개 들어있는지($N$) 개수를 파악해 반복문 횟수를 정할 때 씁니다.

### 39. Concatenate (연결하다)
- **한 줄 뜻**: 두 개 이상의 문자열이나 리스트를 나란히 이어 붙이는 동작
- **코딩 사용 이유**: `"Hello" + "World"`처럼 쪼개진 텍스트나 데이터를 하나로 연결할 때 씁니다.

### 40. Cast (타입 변환하다)
- **한 줄 뜻**: 데이터 타입을 다른 타입으로 강제로 바꾸는 행위
- **코딩 사용 이유**: 문자열 `"100"`을 숫자 `100`으로 바꾸는(`int("100")`) 등 연산을 위한 형태 변환에 쓰입니다.
