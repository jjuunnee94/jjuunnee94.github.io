### 11. Function (함수)
- **한 줄 뜻**: 입력값을 받아 특정 작업을 수행하고 결과를 내놓는 코드 묶음
- **코딩 사용 이유**: 반복되는 코드 로직을 하나로 묶어 필요할 때마다 이름으로 호출함으로써 코드의 재사용성을 극대화합니다.

### 12. Parameter (매개변수)
- **한 줄 뜻**: 함수를 정의할 때 입력을 받기 위해 선언하는 변수
- **코딩 사용 이유**: 함수 내부로 전달받은 데이터($x$)를 받아 작동할 수 있도록 통로 역할을 하는 변수명을 지정합니다.

### 13. Argument (인자 / 전달인자)
- **한 줄 뜻**: 함수를 실제로 호출할 때 넘겨주는 실제 데이터 값
- **코딩 사용 이유**: 함수를 사용할 때 매개변수 위치에 실제 계산할 숫자나 문자 데이터($5$, `"hello"`)를 넣어 전달합니다.

### 14. Return (반환하다)
- **한 줄 뜻**: 함수 실행 결과를 바깥으로 돌려주는 키워드
- **코딩 사용 이유**: 함수 내부에서 계산한 최종 결과값을 밖으로 넘겨주어 다른 변수에 저장하거나 추가 연산에 활용하게 합니다.

### 15. List (리스트 / 목록)
- **한 줄 뜻**: 여러 데이터 항목을 순서대로 나열해 담는 대괄호(`[]`) 자료구조
- **코딩 사용 이유**: 연관된 여러 값들을 하나의 변수에 묶어 관리하고, 인덱스를 통해 언제든 꺼내 쓰기 위해 사용합니다.

### 16. Index (인덱스 / 위치 번호)
- **한 줄 뜻**: 리스트나 문자열 요소의 순서 번호 ($0$부터 시작)
- **코딩 사용 이유**: 순서가 있는 순열 데이터에서 특정 위치($x[0]$)의 값을 지정해 가져오거나 수정할 때 쓰입니다.

### 17. Slicing (슬라이싱 / 자르기)
- **한 줄 뜻**: 데이터 목록의 일부분을 콜론(`:`)으로 잘라내는 기법
- **코딩 사용 이유**: 리스트나 텍스트에서 원하는 시작 위치부터 끝 위치까지 범위 데이터($x[1:4]$)만 부분적으로 추출할 때 사용합니다.

### 18. Boolean (불리언 / 논리형)
- **한 줄 뜻**: 참(`True`) 또는 거짓(`False`)만을 가지는 데이터 타입
- **코딩 사용 이유**: 조건식의 성립 여부를 판단하여 프로그램의 실행 흐름을 결정짓는 기틀이 됩니다.

### 19. Operator (연산자)
- **한 줄 뜻**: 계산을 수행하는 기호 (`+`, `-`, `*`, `/`, `==`)
- **코딩 사용 이유**: 수식 덧셈, 뺄셈이나 두 값의 크기 비교 등 프로그래밍에서 값을 다루는 기호를 제공합니다.

### 20. Condition (조건)
- **한 줄 뜻**: 참과 거짓을 판가름하는 비교 수식
- **코딩 사용 이유**: 특정 상황이나 데이터 상태에 따라 코드를 실행할지 말지를 판단하는 기준이 됩니다.
