### 41. Split (쪼개다 / 나누다)
- **한 줄 뜻**: 하나의 문자열을 구분 기호 기준 여러 개로 나누어 리스트로 만드는 함수
- **코딩 사용 이유**: 쉼표로 연결된 데이터(`"a,b,c"`)나 문장을 단어별로 쪼개어 다룰 때 쓰입니다.

### 42. Join (결합하다)
- **한 줄 뜻**: 리스트 속 문자열 항목들을 하나로 이어 붙여 하나의 문장으로 만드는 함수
- **코딩 사용 이유**: 쪼개진 단어 리스트를 공백이나 구분자를 넣어 다시 보기 좋은 텍스트로 합칠 때 사용합니다.

### 43. Replace (대체하다 / 바꾸다)
- **한 줄 뜻**: 문자열 내의 특정 텍스트를 다른 텍스트로 전부 바꾸는 함수
- **코딩 사용 이유**: 텍스트 전처리 시 불필요한 단어나 오탈자를 원하는 문자로 일괄 교체할 때 씁니다.

### 44. Strip (제거하다 / 다듬다)
- **한 줄 뜻**: 문자열 양 끝의 쓸데없는 공백이나 줄바꿈 문자를 지워주는 함수
- **코딩 사용 이유**: 사용자 입력값 양 끝에 들어간 보기 싫은 띄어쓰기 여백을 깔끔하게 제거할 때 씁니다.

### 45. Format (형식을 맞추다)
- **한 줄 뜻**: 문자열 사이에 변수 값을 예쁘게 끼워 넣는 표현 방식
- **코딩 사용 이유**: f-string(`f"이름: {name}"`) 등을 이용해 결과 문장 속에 변수를 깔끔하게 삽입할 때 사용합니다.

### 46. Lower / Upper (소문자 / 대문자 변환)
- **한 줄 뜻**: 영문 텍스트 전체를 소문자나 대문자로 통일 변환하는 함수
- **코딩 사용 이유**: 대소문자 구문 없이 영문 텍스트를 비교하거나 수집 텍스트를 정형화할 때 씁니다.

### 47. Find / Index (찾다 / 위치 탐색)
- **한 줄 뜻**: 문자열 내에서 특정 문자가 처음 나타나는 위치 번호를 구하는 함수
- **코딩 사용 이유**: 텍스트 안에서 원하는 알파벳이나 단어가 어디에 포함되어 있는지 탐색할 때 사용합니다.

### 48. Count (개수 세기)
- **한 줄 뜻**: 특정 값이나 문자가 데이터 목록에 총 몇 번 나오는지 세는 함수
- **코딩 사용 이유**: 리스트나 텍스트에서 빈도수를 조사하거나 특정 단어 등장 횟수를 파악할 때 쓰입니다.

### 49. In (내부에 존재하는)
- **한 줄 뜻**: 특정 값이 리스트나 텍스트에 포함되어 있는지 확인하는 논리 연산자
- **코딩 사용 이유**: `"apple" in list` 처럼 찾고자 하는 데이터가 존재하는지 참/거짓으로 검사합니다.

### 50. Slice (부분 자르기 객체)
- **한 줄 뜻**: 인덱스 범위를 지정하여 부분 집합을 추출하는 구문
- **코딩 사용 이유**: 정해진 구역의 데이터를 안전하게 꺼내어 원본을 손상시키지 않고 참조하기 위해 쓰입니다.
