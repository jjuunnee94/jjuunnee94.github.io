## 1. 순서가 있는 데이터

- 시퀀스: 순서가 의미를 갖는 값의 묶음
- 평균만 남기면 최근 값과 변화 방향을 알 수 없음
- RNN: 현재 입력과 이전 상태로 새 상태를 계산하는 신경망

📍[예시] $[2,\ 1,\ -1]$과 $[-1,\ 1,\ 2]$

- 평균은 둘 다 0.667
- 마지막 값은 $-1$과 $2$, 변화 방향은 감소와 증가

## 2. MLP · 1D CNN · RNN 비교

| 구조 | 연결 방식 | 가중치 사용 |
|:---:|:---:|:---:|
| MLP | 정해진 위치의 값을 함께 입력 | 위치마다 따로 |
| 1D CNN | 이웃한 구간에 같은 필터 적용 | 같은 필터를 재사용 |
| **RNN** | **이전 상태를 다음 시점으로 전달** | **같은 가중치를 시간마다 재사용** |

- 세 구조 모두 순서를 사용할 수 있고, 차이는 연결과 가중치 재사용 방식

## 3. RNNCell 상태 계산

- 은닉 상태 $h$: 지금까지 읽은 입력이 반영된 특징
- RNNCell: 한 시점을 계산, RNN 층: 여러 시점을 계산
- tanh: 값을 $-1 \sim 1$로 누르는 비선형 함수, 부호는 유지

📐[공식]

$$a_t = W_{ih}x_t + b_{ih} + W_{hh}h_{t-1} + b_{hh}, \qquad h_t = \tanh(a_t)$$

- $x_t$: 현재 입력, $h_{t-1}$: 직전 상태 ($h_0 = 0$)
- $W_{ih}$: 입력 가중치, $W_{hh}$: 상태 가중치, $b$: 편향
- $a_t$: tanh를 적용하기 전의 가중합

📍[예시] $W_{ih}=0.6,\ W_{hh}=0.5,\ b=b_{ih}+b_{hh}=0.1,\ h_0=0,\ x=[2,\ 1,\ -1]$

| 시점 | $x_t$ | $W_{ih}x_t$ | $W_{hh}h_{t-1}$ | $+\,b$ | $a_t$ | $h_t=\tanh(a_t)$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | 2 | 1.2 | 0.5×0 = 0 | 0.1 | 1.3 | **0.861723** |
| 2 | 1 | 0.6 | 0.5×0.861723 = 0.430862 | 0.1 | 1.130862 | **0.811314** |
| 3 | −1 | −0.6 | 0.5×0.811314 = 0.405657 | 0.1 | −0.094343 | **−0.094064** |

- 이전 상태의 몫(+0.405657)이 입력의 몫(−0.6)을 일부 상쇄
- 같은 값을 $[-1,\ 1,\ 2]$ 순서로 넣으면 $h_3 = 0.908466$이므로 순서가 최종 상태를 바꿈

## 4. 상태 유지와 초기화

- 유지: 직전 $h$를 그대로 전달, 이전 상태의 몫이 포함됨
- 초기화: 직전 상태를 0으로 바꿈, 이전 상태의 몫만 사라지고 입력의 몫은 남음
- 가중치는 그대로이며 새로 만들지 않음

📍[예시] 시점 2 ($x_2=1$)

- 유지: $a_2 = 1.130862$ → $h_2 = 0.811314$
- 초기화: $a_2 = 0.6 + 0 + 0.1 = 0.7$ → $h_2 = 0.604368$

⚠️[주의] 값이 커질지 작아질지는 사라지는 이전 상태 몫의 부호에 따라 달라진다.

## 5. 시점 T와 층 K

- $T$: 입력의 길이(시점 수), 가로 방향, 같은 층의 같은 가중치를 반복
- $K$: 층 수, 세로 방향, 아래 층의 $h$가 위 층의 입력, 층마다 가중치가 따로
- Cell 계산 횟수 = $T \times K$
- 가중치 수는 $K$에 비례하고 $T$와 무과

📍[예시]

| 조건 (입력 1개·상태 1개, 편향 포함) | Cell 계산 횟수 | 가중치 수 |
|:---:|:---:|:---:|
| $T=3,\ K=1$ | 3 | 4 |
| $T=5,\ K=1$ | 5 | 4 |
| $T=3,\ K=2$ | 6 | **8** |

## 6. 💻 [코드]

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jjuunnee94/jjuunnee94.github.io/blob/main/notebooks/rnn_practice.ipynb)

```python
import torch                                       # 파이토치
from torch import nn                               # 신경망 모듈

cell = nn.RNNCell(1, 1).double()                   # 입력 1개 → 상태 1개, float64
with torch.no_grad():                              # 값 설정은 미분 기록에 넣지 않음
    cell.weight_ih.fill_(0.6)                      # W_ih = 0.6 (모든 원소를 채움)
    cell.weight_hh.fill_(0.5)                      # W_hh = 0.5
    cell.bias_ih.fill_(0.1)                        # b_ih = 0.1
    cell.bias_hh.fill_(0.0)                        # b_hh = 0

h = torch.zeros(1, 1, dtype=torch.float64)         # h0 = 0, 모양 (예제 수, 상태 수)
for x in [2.0, 1.0, -1.0]:                         # 시점 순서대로 입력
    xt = torch.tensor([[x]], dtype=torch.float64)  # 모양 (1, 1) 텐서로 변환
    h = cell(xt, h)                                # (현재 입력, 직전 상태) → 새 상태
    print(round(h.item(), 6))                      # 상태 값 하나를 꺼내 출력
```
