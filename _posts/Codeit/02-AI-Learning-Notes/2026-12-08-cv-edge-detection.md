## 1. 이웃 값의 차이와 Sobel 필터

- 경계(edge): 밝기가 급하게 바뀌는 곳
- 필터 `[−1, 0, 1]` = 오른쪽 이웃 − 왼쪽 이웃 → 평평한 곳은 0, 경계에서만 값이 커짐

| 입력 | 계산 | 결과 |
|:---:|:---:|:---:|
| 어두움 → 밝음 `[0, 0, 0, 150, 150, 150]` | 칸마다 (오른쪽 − 왼쪽) | `[0, 150, 150, 0]` |
| 밝음 → 어두움 `[150, 150, 150, 0, 0, 0]` | 같은 계산 | `[0, −150, −150, 0]` |

- 밝아지는 경계는 **+**, 어두워지는 경계는 **−**
- 기울기(gradient): 밝기가 얼마나 급하게 변하는지 / Sobel 필터는 3×3 필터 두 개로 가로 기울기(Gx)와 세로 기울기(Gy)를 따로 구함

| 필터 | 모양 | 찾는 경계 |
|:---:|:---:|:---:|
| 가로 기울기(Gx) | `[[−1, 0, 1], [−2, 0, 2], [−1, 0, 1]]` | 세로선 (좌우로 밝기가 변하는 곳) |
| 세로 기울기(Gy) | `[[−1, −2, −1], [0, 0, 0], [1, 2, 1]]` | 가로선 (위아래로 밝기가 변하는 곳) |

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 기울기 크기 | 기울기 크기 G = √(가로 기울기 Gx² + 세로 기울기 Gy²) | $G = \sqrt{G_x^{2} + G_y^{2}}$ |

📍[예시] 3×3 조각 `[[0, 0, 100], [0, 0, 100], [0, 0, 100]]` (왼쪽 어둡고 오른쪽 밝음)

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 가로 기울기(Gx) | (−1×0 + 0 + 1×100) + (−2×0 + 0 + 2×100) + (−1×0 + 0 + 1×100) | 400 |
| 세로 기울기(Gy) | 위 줄 (0·(−1) + 0·(−2) + 100·(−1)) + 아래 줄 (0·1 + 0·2 + 100·1) | 0 |
| 기울기 크기(G) | √(400² + 0²) | **400** |

- 비스듬한 경계에서 Gx = 300, Gy = 400이면 G = √(90,000 + 160,000) = **500**
- 경계의 방향은 기울기 방향에 **수직**

## 2. 기울기의 자료형과 잡음

- 기울기는 음수가 나올 수 있음 → `cv2.CV_8U`(uint8)로 받으면 **음수가 0으로 잘리고** 오류 메시지가 없음, `cv2.CV_16S`(int16)는 음수 유지

| 경계 | `CV_8U`로 받은 Gx | `CV_16S`로 받은 Gx |
|:---:|:---:|:---:|
| 어두움 → 밝음 | `[0, 0, 160, 160, 0, 0]` | `[0, 0, 160, 160, 0, 0]` |
| 밝음 → 어두움 | `[0, 0, 0, 0, 0, 0]` (**경계가 사라짐**) | `[0, 0, −160, −160, 0, 0]` |

- 두 방향의 경계를 같은 세기로 보려면 `CV_16S`로 받은 뒤 `np.abs`(절댓값)
- 미분은 잡음도 키움 → 잡음 낀 사진은 **흐린 뒤 미분**

📍[예시] 평평한 곳 `[100, 108, 92, 106, 94, 100, 100]` (실제 값 100, 잡음 포함)

| 순서 | 결과 |
|:---:|:---:|
| 바로 미분 | `[−8, −2, 2, −6, 6]` (평평한데 ±8) |
| 3칸 평균으로 흐린 뒤 미분 | 흐린 값 `[100, 102, 97.3, 100, 98]` → `[−2.7, −2, 0.7]` |

## 3. Canny

| 순서 | 단계 | 하는 일 |
|:---:|:---:|:---:|
| 1 | 평활 | 가우시안으로 잡음 제거 |
| 2 | 기울기 | Sobel로 Gx, Gy, G 계산 |
| 3 | 얇게 | 기울기가 가장 큰 곳만 남겨 선을 1픽셀로 |
| 4 | 연결 | **높은 임계값 이상**은 확실한 경계, **낮은 임계값 이상**이면서 확실한 경계와 이어지면 경계 |

## 4. 💻 [코드]
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jjuunnee94/jjuunnee94.github.io/blob/main/notebooks/cv_practice.ipynb)

```python
import numpy as np                                                  # 배열 라이브러리
import cv2                                                          # OpenCV

g = np.zeros((5, 6), dtype=np.uint8)                                # 5×6 검은 사진
g[:, 3:] = 40                                                       # 3번 열부터 오른쪽을 40으로(밝음)
g2 = np.full((5, 6), 40, dtype=np.uint8)                            # 5×6 밝은 사진
g2[:, 3:] = 0                                                       # 3번 열부터 오른쪽을 0으로(어두움)

gx8 = cv2.Sobel(g, cv2.CV_8U, 1, 0, ksize=3)                        # 가로 기울기, uint8로 받음 (dx=1, dy=0)
gx16 = cv2.Sobel(g, cv2.CV_16S, 1, 0, ksize=3)                      # 가로 기울기, int16으로 받음
print(gx8[2])                                                       # 어두움 → 밝음 경계, 2번 행
print(gx16[2])
print(cv2.Sobel(g2, cv2.CV_8U, 1, 0, ksize=3)[2])                   # 밝음 → 어두움을 uint8로: 음수가 0으로 잘림
r = cv2.Sobel(g2, cv2.CV_16S, 1, 0, ksize=3)                        # 밝음 → 어두움을 int16으로: 음수 유지
print(r[2])
print(np.abs(r)[2])                                                 # 절댓값으로 두 방향을 같은 세기로
```

```python
gy16 = cv2.Sobel(g, cv2.CV_16S, 0, 1, ksize=3)                      # 세로 기울기 (dx=0, dy=1)
mag = np.sqrt(gx16.astype(np.float32) ** 2 + gy16.astype(np.float32) ** 2)   # 기울기 크기 G, 제곱이 커서 float32로
print(mag[2])

c = np.zeros((10, 10), dtype=np.uint8)                              # 10×10 검은 사진
c[:, 5:] = 200                                                      # 오른쪽 절반을 200으로
edges = cv2.Canny(cv2.GaussianBlur(c, (5, 5), 1.4), 50, 150)       # 흐린 뒤 Canny, 낮은 임계값 50, 높은 임계값 150
print(edges[4])                                                     # 경계 픽셀이 255
```
