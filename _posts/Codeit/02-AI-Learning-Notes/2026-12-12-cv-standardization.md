## 1. 표준화

- 정규화(÷255)로 0~1을 만든 뒤, **표준화(standardization)**로 채널마다 평균을 0, 퍼짐을 1 근처로 맞춤
- 채널 평균(μc): 학습 데이터에서 채널 c의 모든 픽셀 값의 평균 / 채널 표준편차(σc): 값이 평균에서 평균적으로 얼마나 퍼져 있는지

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 표준화 | 표준화 값 z = (정규화한 값 x − 채널 평균 μc) ÷ 채널 표준편차 σc | $z = \dfrac{x - \mu_c}{\sigma_c}$ |

📍[예시] 학습 데이터 R 값이 정규화 후 `[0.4, 0.4, 0.6, 0.6]`

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 평균(μ) | (0.4 + 0.4 + 0.6 + 0.6) ÷ 4 | 0.5 |
| 평균과의 차이 | −0.1, −0.1, +0.1, +0.1 | |
| 차이의 제곱 평균 | (0.01 + 0.01 + 0.01 + 0.01) ÷ 4 | 0.01 |
| 표준편차(σ) | √0.01 | **0.1** |
| x = 0.7의 표준화 | (0.7 − 0.5) ÷ 0.1 | **2.0** |

- 사전학습 모델은 ImageNet 학습셋의 채널별 평균·표준편차를 씀 / R 채널은 평균 0.485, 표준편차 0.229 (G는 0.456, 0.224 / B는 0.406, 0.225가 널리 쓰임)

📍[예시] 기준 픽셀 (R, G, B) = (200, 100, 50)

| 채널 | 정규화 값(÷255) | 표준화 계산 | 결과 |
|:---:|:---:|:---:|:---:|
| R | 200 ÷ 255 = 0.7843 | (0.7843 − 0.485) ÷ 0.229 | **1.307** |
| G | 100 ÷ 255 = 0.3922 | (0.3922 − 0.456) ÷ 0.224 | **−0.285** |
| B | 50 ÷ 255 = 0.1961 | (0.1961 − 0.406) ÷ 0.225 | **−0.933** |

- 표준화는 값 범위를 알아서 맞춰 주지 않음 → ÷255를 빠뜨려도 오류 없이 값만 수백으로 커짐
- 표준화 통계는 **학습 데이터에서만** 구함, 검증·시험 데이터를 합쳐 구하면 평가 데이터의 정보가 학습에 들어감

| 이름 | 실제 계산 |
|:---:|:---:|
| torchvision `Normalize` | 채널별 (x − mean) ÷ std = **표준화** |
| Keras `Normalization` 층 | 데이터의 평균·분산으로 표준화 |
| scikit-learn `Normalizer` | 표본마다 벡터 길이를 1로(단위 노름) |
| 배치 정규화 층 | 층 안에서 미니배치 통계로 표준화 + γ·β |

- 이 글에서 정규화 = ÷255, 표준화 = (x − μ) ÷ σ / 코드는 이름이 아니라 식을 확인

## 2. 배치 정규화

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 배치 정규화 | γ × (은닉값 h − 미니배치 평균 μB) ÷ √(미니배치 분산 σB² + ε) + β | $\gamma \cdot \dfrac{h - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} + \beta$ |

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---:|
| h | 은닉값 | 모델 층 안의 값 |
| μB, σB² | 미니배치 평균, 분산 | 한 번에 넣은 묶음에서 구함 |
| ε | 엡실론 | 분모가 0이 되는 것을 막는 아주 작은 수 |
| γ, β | 감마, 베타 | 크기와 이동을 맞추는 값, **학습으로 정해짐** |

📍[예시] 미니배치 은닉값 h = `[2, 4, 6, 8]` (ε는 아주 작아 무시)

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 평균(μB) | (2 + 4 + 6 + 8) ÷ 4 | 5 |
| 분산(σB²) | (9 + 1 + 1 + 9) ÷ 4 | 5 |
| 표준화 | (h − 5) ÷ √5 (√5 ≈ 2.236) | −1.342, −0.447, 0.447, 1.342 |
| γ = 2, β = 1 적용 | 2 × 표준화 값 + 1 | −1.683, 0.106, 1.894, 3.683 |

| 항목 | 입력 표준화 | 배치 정규화 |
|:---:|:---:|:---:|
| 위치 | 모델 밖 전처리 | 모델의 층 안 |
| 통계 | 고정 통계 | 학습: 미니배치 / 추론: 이동 평균 |

## 3. 사전학습 모델의 전처리

- 사전학습 모델에는 학습 때와 같은 전처리를 써야 함

| 항목 | 맞출 것 | 관련 글 |
|:---:|:---:|:---:|
| 크기 | `Resize`·`CenterCrop` 크기와 보간 | 07 |
| 채널 순서 | RGB / BGR | 02 |
| dtype과 값 범위 | float32, 0~1 / 0~255 | 01·03 |
| 표준화 통계 | 채널별 평균·표준편차 | 09 |
| 축 순서 | [N, C, H, W] / Keras는 [N, H, W, C] | 03 |

📍[예시] Keras ImageNet 모델의 계열별 전처리, 기준 픽셀 (R, G, B) = (200, 100, 50)

| 방식 | 계산 | 결과 |
|:---:|:---:|:---:|
| caffe (ResNet50) | RGB → BGR 순서로 바꾸고 평균 (103.939, 116.779, 123.68)만 차감 | (50, 100, 200) − 평균 = (−53.939, −16.779, 76.32) |
| tf (MobileNet) | ÷127.5 − 1 | R: 200 ÷ 127.5 − 1 = 0.569 |
| torch (DenseNet) | ÷255 → ImageNet 평균·표준편차 | R: 1.307 |

- 일부 계열(EfficientNet, ConvNeXt)은 전처리를 모델 안에 두고 0~255 입력을 받음
- 전처리 정보는 숫자로 외우지 않고 라이브러리에서 불러옴

| 라이브러리 | 불러오는 코드 |
|:---:|:---:|
| torchvision | `weights.transforms()` |
| Hugging Face | `AutoImageProcessor.from_pretrained(...)` |
| timm | `pretrained_cfg`, `create_transform(...)` |
| Keras | 모델 모듈의 `preprocess_input` |

- 같은 ResNet50도 torchvision V1은 256 → 224, V2는 232 → 224

🔍[비교] 평가 때 전처리를 바꿨을 때 (MNIST 작은 CNN, 강의 LAB 5)

| 평가 때 전처리 | 평균 정확도 | 평균 손실 | 확률 > 0.999 비율 |
|:---:|:---:|:---:|:---:|
| 바른 전처리 | 0.9818 | 0.06 | 0.585 |
| ÷255 생략 | 0.9802 | **9.27** | **0.999** |
| 다른 통계(0.485, 0.229) | **0.9152** | 0.30 | 0.526 |

- ÷255를 생략해도 정확도는 거의 그대로지만 손실이 커지고 거의 모든 예측에 99.9% 이상 확신 → 정확도만 보면 전처리 오류를 놓칠 수 있음

## 4. 💻 [코드]

```python
import numpy as np                                            # 배열 라이브러리
import torch                                                  # PyTorch
from torchvision.transforms import v2                         # 이미지 변환 모음

MEAN = [0.485, 0.456, 0.406]                                  # 채널별 평균 (R, G, B 순서)
STD = [0.229, 0.224, 0.225]                                   # 채널별 표준편차

tf = v2.Compose([v2.ToImage(),                                # 1) HWC → CHW
                 v2.ToDtype(torch.float32, scale=True),       # 2) float32로 바꾸고 ÷255
                 v2.Normalize(MEAN, STD)])                    # 3) (x − 평균) ÷ 표준편차, 채널마다

img = np.array([[[200, 100, 50]]], dtype=np.uint8)            # 픽셀 하나, 모양 (1, 1, 3)
print(tf(img)[:, 0, 0])                                       # 모든 채널, 0번 행 0번 열
```

```python
h = np.array([2, 4, 6, 8], dtype=np.float64)                  # 미니배치 은닉값
mu, var = h.mean(), h.var()                                   # 미니배치 평균, 분산
gamma, beta, eps = 2.0, 1.0, 1e-5                             # γ, β, ε
out = gamma * (h - mu) / np.sqrt(var + eps) + beta            # 배치 정규화 식
print(mu, var)
print(out.round(3))                                           # 소수 셋째 자리까지
```
