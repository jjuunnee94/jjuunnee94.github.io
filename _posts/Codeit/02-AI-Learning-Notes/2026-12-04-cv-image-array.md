## 1. 컴퓨터 비전과 이미지 표현

- 컴퓨터가 받는 입력은 0~255 정수가 모인 배열
- 컴퓨터 비전(computer vision): 디지털 이미지에서 정보를 추출하는 분야
- 밝기·크롭·좌우 반전만으로 같은 위치의 값이 바뀜 → 좌표별 값이 아니라 **숫자 사이의 관계**로 판단
- 숫자 개수 = 높이(H) × 너비(W) × 채널 수(C) / $H \times W \times C$

| 태스크 | 출력 | 예 |
|:---:|:---:|:---:|
| **분류(classification)** | 사진 한 장당 **라벨 하나** | "이 사진은 고양이" |
| **검출(detection)** | **바운딩 박스(bounding box)**(물체를 감싼 사각형) + 라벨 | "(130, 80)~(210, 150)에 눈" |
| **세그멘테이션(segmentation)** | **픽셀마다 라벨** | "이 픽셀은 털, 저 픽셀은 배경" |

📍[예시] 요구에서 필요한 출력의 모양을 보고 과제를 고른다.

| 요구 | 필요한 출력 | 과제 |
|:---:|:---:|:---:|
| 사진 속 자동차가 몇 대인지 세기 | 자동차마다 위치(박스)가 있어야 셀 수 있음 | **검출** |
| 하늘 영역만 파랗게 바꾸기 | 픽셀마다 하늘인지 아닌지 라벨이 필요 | **세그멘테이션** |
| 사진이 강아지인지 판정하기 | 사진 한 장당 라벨 하나면 충분 | **분류** |

## 2. 디지털 이미지

- 샘플링(sampling): **위치**를 일정 간격 칸으로 나눔 → 칸 하나가 픽셀(pixel)
- 양자화(quantization): **밝기**를 정수 단계(0~255)로 반올림
- NumPy 배열은 (높이 H, 너비 W, 채널 수 C), Pillow `size`는 (너비 W, 높이 H) → 같은 사진이 `(240, 320, 3)`과 `(320, 240)`
- 채널(channel): 픽셀마다 같은 종류의 값을 모은 격자 한 장, 컬러 = 빨강(R)·초록(G)·파랑(B) 세 장
- uint8: 부호 없는 8비트 정수, $2^8 = 256$단계라서 **0~255**만 담음 (MNIST 28 × 28 회색, CIFAR-10 32 × 32 × 3도 uint8)

📍[예시] `(480, 640, 3)` 사진의 숫자 개수

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 픽셀 수 | 높이(H) × 너비(W) = 480 × 640 | 307,200개 |
| 픽셀 하나의 숫자 수 | 채널 수(C) = R, G, B | 3개 |
| 전체 숫자 수 | 307,200 × 3 | **921,600개** |

📐 **회색 변환**: 채널 3개를 가중합해 채널 1개(밝기)로 바꾼다.

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 회색 변환 | 밝기 Y = 0.299 × 빨강 R + 0.587 × 초록 G + 0.114 × 파랑 B | $Y = 0.299R + 0.587G + 0.114B$ |

- 밝기 성분(Y, luma)만 남고 색상·채도는 사라짐
- 가중치는 라이브러리마다 다름 (scikit-image는 0.2125·0.7154·0.0721)

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 기준 픽셀 | (R, G, B) = (200, 100, 50) | |
| 빨강 항 | 0.299 × 200 | 59.8 |
| 초록 항 | 0.587 × 100 | 58.7 |
| 파랑 항 | 0.114 × 50 | 5.7 |
| 합 | 59.8 + 58.7 + 5.7 | 124.2 |
| 정수로 반올림 | | **124** |

## 3. 💻 [코드]
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jjuunnee94/jjuunnee94.github.io/blob/main/notebooks/cv_practice.ipynb)

```python
import numpy as np                                    # 숫자 배열 라이브러리를 np로 불러옴

img = np.array([[[200, 100, 50], [10, 20, 30]],       # 0번 행: 픽셀 2개, 픽셀마다 (R, G, B)
                [[0, 255, 128], [90, 90, 90]]],       # 1번 행: 픽셀 2개
               dtype=np.uint8)                        # 각 숫자를 uint8(0~255)로 저장

print("shape:", img.shape)                            # (높이 H, 너비 W, 채널 수 C)
print("dtype:", img.dtype)                            # 저장된 숫자의 자료형
print("size:", img.size)                              # 배열 안 숫자의 총 개수
print("img[1, 0] =", img[1, 0])                       # [행, 열] → 1번 행 0번 열의 픽셀 전체
print("img[0, 1, 2] =", img[0, 1, 2])                 # 세 번째 번호는 채널(0=R, 1=G, 2=B)
```

```
shape: (2, 2, 3)
dtype: uint8
size: 12
img[1, 0] = [  0 255 128]
img[0, 1, 2] = 30
```
