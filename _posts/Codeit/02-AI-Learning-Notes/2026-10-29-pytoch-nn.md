### 1. 모델을 묶는 이유

```python
w = torch.tensor([[0.]], requires_grad=True)
b = torch.zeros(1, requires_grad=True)
optimizer = torch.optim.SGD([w, b], lr=0.05)
```

- 파라미터가 많아지면 `[w1, b1, w2, b2, ...]`를 직접 나열하다가 빠뜨리기 쉽다.
- `nn.Module`: 파라미터와 예측 계산을 한 모델로 묶어준다.
- `model.parameters()` 전체 파라미터를 optimizer에 전달

### 2. nn.Module로 모델 만들기

- `nn.Module`: 파이토치가 제공하는 모델용 기본 설계도. 이를 상속받아 내 모델을 만든다.
- **`__init__()`**: 모델을 만들 때 **사용할 파라미터(w, b)와 레이어(nn.Linear 등)를 등록**하는 곳.
- **`forward()`**: 입력 data(`x`)가 들어왔을 때 **순전파(예측) 계산을 수행**하는 곳. `model(x)`를 호출하면 실행된다.

```python
import torch
from torch import nn

class MyLine(nn.Module):
    def __init__(self):
        super().__init__()                          # 초기 세팅
        self.w = nn.Parameter(torch.zeros(1, 1))    # 파라미터 등록
        self.b = nn.Parameter(torch.zeros(1))

    def forward(self, x):                           # 예측 계산 정의 (순전파)
        return x @ self.w + self.b

model = MyLine()                                    # 모델 객체 생성
x = torch.tensor([[1.], [2.], [3.]])
print(model(x))

for p in model.parameters():
    print(p.shape)
```

```
torch.Size([1, 1]) # 모델이 등록해 둔 파라미터(`w`, `b`)를 차례로 반환(shape).
torch.Size([1])
```

### 3. nn.Linear

- `nn.Linear` = `x @ w + b`  (위 `MyLine`을 한 줄로 대체)

```python
model = nn.Linear(입력 특성 개수, 출력 개수)
```

- `nn.Linear(1, 1)`: 입력 1개 → 출력 1개
- `nn.Linear(2, 3)`: 입력 특성 2개 → 예측 3개
- 내부 파라미터: `weight`(가중치), `bias`(편향)

**weight의 shape는 (출력, 입력) → 내부 계산은 `weight`를 전치(`.T`)해서 사용**

```python
linear = nn.Linear(2, 3)
print(linear.weight.shape)     # torch.Size([3, 2])
print(linear.bias.shape)       # torch.Size([3])

x = torch.zeros(5, 2)
print(linear(x).shape)         # torch.Size([5, 3])
```
```
x @ weight.T + bias
(5, 2) @ (2, 3) → (5, 3),  + (3,) → (5, 3)
```

### 4. 파라미터 등록 (nn.Parameter)

- 모델 안에서 `nn.Parameter`로 감싼 값만 파라미터로 등록되어 `model.parameters()`에 포함된다.

```python
class Demo(nn.Module):
    def __init__(self):
        super().__init__()
        self.w = nn.Parameter(torch.zeros(1, 1))   # 파라미터로 등록
        self.k = torch.zeros(2, 2)                 # 일반 Tensor

demo = Demo()
for name, p in demo.named_parameters():
    print(name, p.shape)
```

```
w torch.Size([1, 1]) # nn_parameter로 등록한 w 출력
```

### 5. nn.Linear로 학습하기

```python
x = torch.tensor([[1.], [2.], [3.]])
y = torch.tensor([[5.], [8.], [11.]])

model = nn.Linear(1, 1)
with torch.no_grad():
    model.weight.zero_()
    model.bias.zero_()

optimizer = torch.optim.SGD(model.parameters(), lr=0.05)

for epoch in range(1, 5):                      # 학습 4번 실행
    optimizer.zero_grad()                      # 기울기 초기화
    pred = model(x)                            # 예측
    loss = ((pred - y) ** 2).mean()            # 손실 (평균)
    loss.backward()                            # 기울기 계산
    optimizer.step()                           # 파라미터 갱신
    
    w_val = model.weight.item()
    b_val = model.bias.item()
    print(f"Epoch {epoch} | Loss: {loss.item():.4f} | w: {w_val:.4f}, b: {b_val:.4f}")
```

```
Epoch 1 | Loss: 70.0000 | w: 1.2333, b: 0.5333
Epoch 2 | Loss: 13.9200 | w: 2.0500, b: 0.8800
Epoch 3 | Loss: 2.7963  | w: 2.5200, b: 1.0800
Epoch 4 | Loss: 0.5891  | w: 2.7800, b: 1.2000

목표값 y = 3x + 2이므로 w → 3, b → 2를 향하고 있음
```
