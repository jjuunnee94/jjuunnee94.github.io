## 1. 기울기 소실과 폭주

- 역전파에서 한 시점을 거슬러 갈 때마다 같은 종류의 배율이 곱해짐
- 배율이 1보다 작으면 앞 시점으로 갈수록 신호가 0에 가까워짐 → **소실**
- 배율이 1보다 크면 신호가 점점 커짐 → **폭주**
- 긴 의존성(멀리 떨어진 입력이 필요한 과제의 성질)과 기울기 소실(학습 신호가 작아지는 현상)은 서로 다른 대상
- gradient clipping: 너무 큰 기울기의 크기를 한도까지 줄임, 이미 사라진 신호는 복원하지 못함
- 소실에는 상태를 전달하는 경로를 바꾼 LSTM·GRU를 사용 

📐[공식] $H=1$일 때

$$\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^{T} W_{hh}\,(1-h_k^2)$$

- $W_{hh}(1-h_k^2)$: 한 시점을 건너는 배율, 시점 수만큼 연달아 곱해짐
- $1-h_k^2$는 항상 1 이하이고, 상태가 $\pm1$에 가까울수록 작아짐
- 상태가 여러 칸이면 배율이 행렬이고 그 행렬을 곱함

📍[예시] 처음 크기 1, 매 단계 같은 배율

| 가정 | 1번 | 2번 | 3번 | 4번 | 5번 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| ×0.6 | 0.6 | 0.36 | 0.216 | 0.1296 | **0.07776** |
| ×1.4 | 1.4 | 1.96 | 2.744 | 3.8416 | **5.37824** |

## 2. LSTM의 두 상태와 게이트

- 셀 상태 $c$: 보존과 쓰기가 누적된 저장 공간
- 은닉 상태 $h$: 지금 밖으로 드러낼 특징
- 게이트: 가중합 $a$에 시그모이드 $\sigma$를 적용한 0~1의 조절 비율, 비율 0.25 × 대상 0.8 = 반영값 0.2
- 후보 $g$: tanh로 만든 새 내용 (−1~1)

📐[공식]

$$\sigma(a)=\frac{1}{1+e^{-a}}, \qquad c_t = f_t \odot c_{t-1} + i_t \odot g_t, \qquad h_t = o_t \odot \tanh(c_t)$$

- $\odot$: 같은 칸끼리 곱하는 원소곱
- $\sigma(2)=0.8808,\ \sigma(0)=0.5,\ \sigma(-2)=0.1192$

| 기호 | 이름 | 역할 | 활성화 |
|:---:|:---:|:---:|:---:|
| $f$ | Forget gate | 이전 셀 상태에서 남길 비율 | $\sigma$ |
| $i$ | Input gate | 새 후보를 저장에 반영할 비율 | $\sigma$ |
| $g$ | Candidate | 이번에 새로 저장할 내용 | tanh |
| $o$ | Output gate | 셀 상태를 은닉 출력에 반영할 비율 | $\sigma$ |

📍[예시] 한 칸, $c_{t-1}=0.8,\ f=0.5,\ i=0.9,\ g=-0.4$

| 보존분 $f\,c_{t-1}$ | 반영분 $i\,g$ | $c_t$ |
|:---:|:---:|:---:|
| 0.5×0.8 = 0.4 | 0.9×(−0.4) = −0.36 | **0.04** |

## 3. 게이트 생성과 한 시점의 흐름

- 네 경로는 같은 $x_t$, $h_{t-1}$을 받지만 가중치와 활성화가 따로
- ① 네 가중합 계산 → ② $f,\ i,\ g,\ o$ 생성 → ③ $c_t$ 갱신 → ④ $h_t$ 생성 → ⑤ $c_t,\ h_t$를 다음 시점에 전달
- $c_{t-1}$에서 $c_t$로 가는 직접 경로의 배율은 $f$ 하나, $f$가 1에 가까우면 이전 값이 거의 그대로 전달됨

📐[공식] 경로 $q \in \{f,\ i,\ g,\ o\}$

$$a_q = W_{xq}\,x_t + W_{hq}\,h_{t-1} + b_q$$

- $W_{xq}$: 입력 가중치, $W_{hq}$: 상태 가중치, $b_q$: 입력 편향과 상태 편향의 합
- $f=\sigma(a_f),\ i=\sigma(a_i),\ g=\tanh(a_g),\ o=\sigma(a_o)$

📍[예시] forget gate, $x_t=-0.5,\ h_{t-1}=0.6,\ c_{t-1}=0.8,\ W_{xf}=0.8,\ W_{hf}=-0.3,\ b_f=0.2$

| 입력 기여 | 이전 은닉 기여 | $+\,b_f$ | $a_f$ | $f=\sigma(a_f)$ | 남은 셀 상태 $f\,c_{t-1}$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0.8×(−0.5) = −0.4 | −0.3×0.6 = −0.18 | 0.2 | −0.38 | **0.4061** | **0.3249** |

## 4. RNN과 LSTM 비교

| 비교 | RNN | LSTM |
|:---:|:---:|:---:|
| 전달하는 상태 | $h$ | $h$와 $c$ |
| 가중합 개수 | 1개 | 4개 |
| 상태 갱신 | $h_t=\tanh(a_t)$ | $c_t=f\odot c_{t-1}+i\odot g$, $h_t=o\odot\tanh(c_t)$ |
| 이전 정보 전달 | 매번 $W_{hh}$와 tanh를 통과 | $c$에 비율 $f$를 곱해 전달 |

- 입력 1칸, 상태 1칸이면 가중치와 편향은 RNN 4개, LSTM $4\times(1+1+2)=16$개

## 5. 💻 [코드]

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jjuunnee94/jjuunnee94.github.io/blob/main/notebooks/rnn_practice.ipynb)

```python
import torch                                              # 파이토치

for rate in [0.6, 1.4]:                                   # 매 단계 곱할 배율 두 가지
    value = 1.0                                           # 처음 크기
    for _ in range(5):                                    # 5번 반복
        value = value * rate                              # 배율을 곱함
    print(rate, round(value, 5))                          # 배율과 5번 곱한 결과

a_f = torch.tensor(0.8 * -0.5 + -0.3 * 0.6 + 0.2)         # 가중합 = 입력 기여 + 이전 은닉 기여 + 편향
f = torch.sigmoid(a_f)                                    # 시그모이드로 0~1 비율로 변환
c_prev = torch.tensor(0.8)                                # 이전 셀 상태
print(round(f.item(), 4), round((f * c_prev).item(), 4))  # 남길 비율, 남은 셀 상태
```
