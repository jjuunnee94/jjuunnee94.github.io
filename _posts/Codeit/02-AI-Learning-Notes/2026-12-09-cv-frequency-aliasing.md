## 1. 공간 주파수

- 공간 주파수(spatial frequency): 일정 거리 안에서 밝기 무늬가 반복되는 횟수
- 저주파: 완만하게 변하는 부분(하늘, 매끈한 털 바탕) / 고주파: 급하게 변하는 부분(경계, 잔털, 잡음)
- 사진은 여러 주파수 무늬를 겹쳐 놓은 합
- 블러(흐리기) = 고주파를 줄이고 저주파를 남김 → **저역 통과(low-pass)**
- 원본 − 블러 = 블러가 지운 성분 → **고역 통과(high-pass)**, 샤프닝 = 고주파를 키움

📍[예시] 입력 I = `[20, 20, 80, 20, 20]`, 박스 필터로 흐린 B = `[40, 40, 40]`, 원본은 같은 위치 `I[1:4] = [20, 80, 20]`

| 칸 | 원본(I) | 저주파(B) | 고주파(I − B) | 확인: B + (I − B) |
|:---:|:---:|:---:|:---:|:---:|
| 1 | 20 | 40 | −20 | 20 |
| 2 | 80 | 40 | **+40** | 80 |
| 3 | 20 | 40 | −20 | 20 |

- 원본 = 저주파(B) + 고주파(I − B) / 고주파는 경계(80)에서만 값이 크고 합이 0
- 샤프닝은 고주파를 한 번 더 더해서 `[0, 120, 0]`처럼 경계를 키움

## 2. 에일리어싱

- 줄일 때 픽셀을 건너뛰어 뽑으면 표본 간격(d)이 넓어짐
- 에일리어싱(aliasing): 표본 간격이 무늬 주기의 절반보다 넓으면 원본에 없던 느린 무늬(가짜 저주파)가 생김

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 에일리어싱 조건 | 무늬 주기 P가 표본 간격 d의 2배보다 짧음 | $P < 2d$ |

📍[예시] 줄무늬 `[0, 100, 0, 100, 0, 100, 0, 100]`, 무늬 주기 P = 2칸

| 표본 간격 d | 뽑은 값 | 판단 | 결과 |
|:---:|:---:|:---:|:---:|
| 1칸(전부) | `[0, 100, 0, 100, 0, 100, 0, 100]` | 2 < 2 아님 | 줄무늬가 보존됨 |
| 2칸 | `[0, 0, 0, 0]` | 2 < 4 | **균일한 검정**: 원본에 없던 무늬 |

- 주기가 긴 무늬는 같은 간격으로 뽑아도 보존됨: `[0, 0, 0, 0, 100, 100, 100, 100]`을 두 번 반복한 줄(P = 8)을 d = 2로 뽑으면 8 < 4가 아니므로 `[0, 0, 100, 100, 0, 0, 100, 100]`

## 3. 줄이기 전에 흐리기

- 줄이는 일은 표본 간격을 넓히는 일 → 줄이기 **전에** 고주파를 먼저 줄임
- 가우시안 `[1/4, 1/2, 1/4]`로 먼저 흐린 뒤 두 칸마다 뽑으면 원본에 없던 값(검정 0)은 막고 세부는 잃음

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 흐리기 | 칸마다 (0×0.25 + 100×0.5 + 0×0.25) = 50, (100×0.25 + 0×0.5 + 100×0.25) = 50 … | `[50, 50, 50, 50, 50, 50]` |
| 두 칸마다 뽑기 | `[::2]` | `[50, 50, 50]` |

- 결과는 원본 평균(50)인 균일한 회색

## 4. 💻 [코드]
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jjuunnee94/jjuunnee94.github.io/blob/main/notebooks/cv_practice.ipynb)

```python
import numpy as np                                         # 배열 라이브러리

I = np.array([20, 20, 80, 20, 20], dtype=np.float64)       # 입력 줄
B = np.correlate(I, np.array([1, 1, 1]) / 3, "valid")      # 박스 필터로 흐림 = 저주파, 3칸
print(B)
print(I[1:4] - B)                                          # B와 같은 위치의 원본 − 블러 = 고주파
```

```
[40. 40. 40.]
[-20.  40. -20.]
```

```python
row = np.array([0, 100, 0, 100, 0, 100, 0, 100], dtype=np.float64)   # 줄무늬, 주기 P = 2칸
print(row[::2])                                            # [시작:끝:간격], 2칸마다 하나씩 뽑기

k = np.array([1, 2, 1]) / 4                                # 가우시안 3칸 근사 [1/4, 1/2, 1/4]
blur = np.correlate(row, k, "valid")                       # 먼저 흐리기
print(blur[::2])                                           # 그다음 2칸마다 뽑기
```

```
[0. 0. 0. 0.]
[50. 50. 50.]
```
