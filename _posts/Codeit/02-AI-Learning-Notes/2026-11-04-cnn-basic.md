### 1. 코드로 보는 이미지
- 컴퓨터에게 이미지는 그림이 아니라 **숫자 표**이다.
- 흑백 이미지는 칸마다 밝기를 나타내는 숫자가 하나씩 들어 있다. MNIST 손글씨는 가로 28칸, 세로 28칸이고, 각 칸은 0(검정)~1(흰색) 값을 가진다.
- 이미지에서 중요한 것은 한 칸의 값만이 아니라 **그 칸 주변에 어떤 값이 있는가**이다.
- 가운데 칸만 밝아도 위아래로 이어져 있으면 세로선의 일부이고, 주변이 다 어두우면 점이다.

### 📍 [예시] 주변 관계에 따른 의미 차이 (가운데 1 값 비교)

| (A) 세로선의 일부 | (B) 단독 점(Dot) |
| :---: | :---: |
| $\begin{pmatrix} 0 & \mathbf{1} & 0 \\ 0 & \mathbf{1} & 0 \\ 0 & \mathbf{1} & 0 \end{pmatrix}$ | $\begin{pmatrix} 0 & 0 & 0 \\ 0 & \mathbf{1} & 0 \\ 0 & 0 & 0 \end{pmatrix}$ |
| **위아래로 이어진 세로선** | **주변이 모두 어두운 점** |

* 두 예시 모두 가운데 위치의 값은 동일하게 **1**이지만, **주변 픽셀과의 관계**에 따라 인공지능이 인식하는 특징이 달라집니다.

### 2. 완전연결층(Fully Connected Layer)

- **완전연결층(Fully Connected Layer)** 은 이미지를 한 줄로 펼친 뒤, 출력 한 칸이 **입력 전체**를 읽는다.
- 5×5 이미지라면 입력이 25개이고, 출력 한 칸은 25개 값을 모두 읽는다.
- 문제는 두 가지이다.
  - 한 줄로 펼치는 순간 "어느 칸이 이웃인지"라는 구조가 모델에서 사라진다.
  - 연결이 많아서 학습할 가중치가 크게 늘어난다.

### 3. 국소 연결(Local Connectivity)

- **국소 연결(Local Connectivity)** 은 출력 한 칸이 입력 전체가 아니라 **가까운 작은 영역**만 읽게 하는 것이다.
- 3×3 영역만 읽는다면 출력 한 칸이 읽는 값은 25개가 아니라 **9개**이다.
- 이웃한 값끼리의 관계를 보도록 구조 자체를 만든 것이다.

### 4. 가중치 공유 : 같은 필터를 재사용하기

- **가중치 공유(Parameter Sharing)** 는 같은 가중치 묶음을 **여러 위치에 재사용**하는 것이다.
- 이 가중치 묶음을 **필터(Filter)** 라고 한다. 3×3 필터에는 가중치가 9개 들어 있고, 이 9개를 이미지의 모든 위치에 똑같이 적용한다.
- 이미지의 특징은 위치와 상관없이 반복된다. 세로선은 왼쪽에 있든 오른쪽에 있든 같은 세로선이므로, 같은 규칙으로 읽으면 위치마다 새로 배울 필요가 없다.
- 가중치가 같아도 필터 아래에 놓이는 **입력 영역이 다르면 결과는 달라질 수 있다.** "같은 규칙으로 읽는다"는 뜻이지 "같은 값이 나온다"는 뜻이 아니다.

### 5. 가중치 개수 비교

- 입력이 5×5(25개)이고 3×3 영역을 한 칸씩 옮기며 읽으면, 필터가 들어갈 수 있는 시작 위치가 가로 3곳, 세로 3곳이므로 출력 위치는 **9개**이다. (크기 공식은 ③에서 다룬다.)
- 편향(bias)은 빼고 곱해지는 가중치만 센다.

| 방식 | 식 | 가중치 개수 |
| --- | --- | --- |
| 완전연결 | 입력 25개 × 출력 9개 | 225 |
| 국소 연결 (공유 X) | 영역 9개 × 출력 9개 | 81 |
| 합성곱 (국소 연결 + 공유) | 필터 하나 (3×3) | 9 |

- 완전연결 `25 × 9 = 225`: 출력 9칸이 각각 입력 25개를 읽고, 연결마다 가중치가 따로 있다.
- 국소 연결 `9 × 9 = 81`: 출력 9칸이 각각 9개만 읽지만, 칸마다 필터가 따로라서 가중치도 따로이다.
- 합성곱 `9`: 출력 9칸이 모두 **같은 필터 9개 값**을 쓴다.

### 6. 코드로 확인하기

```python
import torch
from torch import nn

def count_params(model):
    return sum(p.numel() for p in model.parameters())

x = torch.zeros(1, 1, 5, 5)

fc = nn.Linear(25, 9, bias=False)
conv = nn.Conv2d(1, 1, kernel_size=3, bias=False)

print(fc(x.flatten(start_dim=1)).shape)
print(conv(x).shape)
print(count_params(fc), count_params(conv))
```

```
torch.Size([1, 9])
torch.Size([1, 1, 3, 3])
225 9
```

- `count_params`: 모델의 학습 가능한 값을 세는 함수이다. `model.parameters()`는 weight와 bias를 하나씩 꺼내 주고, `p.numel()`은 그 Tensor의 원소 개수이다.
- `torch.zeros(1, 1, 5, 5)`: 이미지는 `[N, C, H, W]` 4개 축이 필요하다. 이미지 1장, 채널 1개(흑백), 높이 5, 너비 5이다. 모양만 보려는 것이라 값은 모두 0으로 했다.
- `nn.Linear(25, 9, bias=False)`: 입력 25개를 받아 출력 9개를 내는 완전연결층이다. 가중치는 `[9, 25]` 모양이다.
- `x.flatten(start_dim=1)`: 이미지를 한 줄로 펼친다. `start_dim=1`이므로 N축(이미지 수)은 남기고 `[1, 1, 5, 5]`가 `[1, 25]`가 된다. 완전연결층은 한 줄로 펼친 입력을 받기 때문이다.
- `nn.Conv2d(1, 1, kernel_size=3, bias=False)`: 입력 채널 1, 출력 채널 1, 3×3 필터 하나를 가진 합성곱 층이다. 가중치는 `[1, 1, 3, 3]` 모양이고 원소는 9개이다. 합성곱은 이미지를 펼치지 않고 `[N, C, H, W]` 그대로 받는다.
- 출력 모양: Linear는 `[1, 9]`로 숫자 9개가 한 줄로 나오고, Conv2d는 `[1, 1, 3, 3]`으로 3×3 표가 나온다. 합성곱은 출력도 위치 관계를 가진다.
- `225 9`: 표에서 센 값과 같다.

### 7. 주의할 점

- 가중치 수가 줄었다고 정확도나 속도가 자동으로 좋아지지는 않는다. 같은 필터를 쓰는 **계산 횟수**는 위치 수만큼 그대로 남는다.
- "가까운 값끼리 관계가 있고, 같은 패턴이 여러 위치에 나타난다"는 **가정**이 데이터에 맞을 때 CNN이 효과적이다.
  - 이 가정을 모델 구조에 미리 넣은 것을 **귀납적 편향(Inductive Bias)** 이라고 한다. 더하는 값인 편향(bias)과는 다른 말이다.
