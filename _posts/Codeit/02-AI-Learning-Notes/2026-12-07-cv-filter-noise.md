## 1. 필터링

- 점 연산: 픽셀 하나의 값만 보고 새 값을 만듦 (밝기 +50, 회색 변환)
- 이웃 연산: 주변 픽셀까지 함께 봄 (흐리기, 경계 찾기)
- 필터(filter): 모든 위치에서 같은 가중치 묶음을 이웃에 곱해 더함

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 필터링(교차상관) | 출력 O = 이웃 픽셀 × 같은 위치 필터 값의 합 | $O_i = \sum_{u=-1}^{1} K_u \, I_{i+u}$ |
| 합성곱 | 필터를 뒤집어서 같은 계산 | $O_i = \sum_{u=-1}^{1} K_{-u} \, I_{i+u}$ |

- 좌우 대칭 필터는 교차상관과 합성곱이 같음, 반대칭 필터 `[−1, 0, 1]`은 **부호만 바뀜**

📍[예시] 입력 I = `[20, 20, 80, 20, 20]`, 박스 필터 K = `[1/3, 1/3, 1/3]` (양 끝은 이웃이 부족해 계산하지 않음)

| 위치 | 계산 | 결과 |
|:---:|:---:|:---:|
| 1번 칸 | (20 + 20 + 80) ÷ 3 | 40 |
| 2번 칸 | (20 + 80 + 20) ÷ 3 | 40 |
| 3번 칸 | (80 + 20 + 20) ÷ 3 | 40 |

- 모든 위치에 같은 가중치를 곱하므로 80이 한 칸에서 사라지지 않고 이웃으로 번짐

| 방법 | 입력 `[10, 10, 10, 60, 10, 10, 10]`, 필터 `[−1, 0, 1]` |
|:---:|:---:|
| `np.correlate(…, "valid")` | `[0, 50, 0, −50, 0]` |
| `np.convolve(…, "valid")` | `[0, −50, 0, 50, 0]` |

## 2. 가우시안 필터와 중앙값 필터

- 가우시안 필터: 가까운 이웃에 큰 가중치, 3칸 근사는 `[1/4, 1/2, 1/4]` / 표준편차(σ)가 클수록 넓게 평균해 더 흐려짐

| 위치 | 박스 `[1/3, 1/3, 1/3]` | 가우시안 `[1/4, 1/2, 1/4]` |
|:---:|:---:|:---:|
| 1번 칸 | (20 + 20 + 80) ÷ 3 = 40 | 20×0.25 + 20×0.5 + 80×0.25 = 35 |
| 2번 칸 | (20 + 80 + 20) ÷ 3 = 40 | 20×0.25 + 80×0.5 + 20×0.25 = **50** |
| 3번 칸 | (80 + 20 + 20) ÷ 3 = 40 | 80×0.25 + 20×0.5 + 20×0.25 = 35 |

- 가우시안 잡음: 모든 픽셀에 작은 값이 더해짐 / 소금·후추 잡음: 일부 픽셀만 0이나 255로 크게 튐
- 중앙값 필터: 이웃 값을 크기순으로 세워 가운데 값을 고름 → 튄 값을 지우고 새 값을 만들지 않음

📍[예시] 입력 `[20, 20, 255, 20, 20]`

| 위치 | 이웃 3칸 | 박스 평균 | 중앙값 |
|:---:|:---:|:---:|:---:|
| 1번 칸 | 20, 20, 255 | 98.3 | **20** |
| 2번 칸 | 20, 255, 20 | 98.3 | **20** |
| 3번 칸 | 255, 20, 20 | 98.3 | **20** |

🔍[비교] 원본과의 평균 절대 오차 (낮을수록 좋음, 강의 LAB 2)

| 잡음 | 박스 5×5 | 가우시안 5×5 | 중앙값 5×5 |
|:---:|:---:|:---:|:---:|
| 가우시안 잡음 | 6.12 | **6.00** | 6.59 |
| 소금·후추 잡음 | 9.40 | 10.15 | **4.25** |

## 3. 샤프닝

- 원본 − 블러 = 블러가 지운 **급한 밝기 변화**, 이것을 원본에 다시 더하면 경계가 강조됨

| 이름 | 말로 푼 식 | 기호 식 |
|:---:|:---:|:---:|
| 샤프닝 | 샤프닝 결과 = 원본 + (원본 − 블러) | $I_{\text{sharp}} = I + (I - B)$ |

📍[예시] 입력 I = `[10, 10, 10, 60, 60, 60]`을 박스 필터(3칸, valid)로 흐린 B = `[10, 26.7, 43.3, 60]`, 원본은 같은 위치 `I[1:5] = [10, 10, 60, 60]`

| 칸 | 원본(I) | 블러(B) | 원본 − 블러 | I + (I − B) | 0~255로 자름 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 10 | 10 | 0 | 10 | 10 |
| 1 | 10 | 26.7 | −16.7 | −6.7 | **0** |
| 2 | 60 | 43.3 | +16.7 | 76.7 | **77** |
| 3 | 60 | 60 | 0 | 60 | 60 |

- 어두운 쪽은 더 어둡게, 밝은 쪽은 더 밝게 → 경계의 차이가 커짐
- 음수는 0~255로 잘라야 함 (uint8 오버플로)

```python
import numpy as np                                          # 배열 라이브러리

row = np.array([20, 20, 80, 20, 20], dtype=np.float64)      # 입력 줄, 소수 계산을 위해 실수형
k = np.array([1, 1, 1]) / 3                                 # 박스 필터 [1/3, 1/3, 1/3]
print(np.correlate(row, k, "valid"))                        # 교차상관, 이웃이 다 있는 위치만 계산
```

```python
import cv2                                                  # OpenCV

img = np.full((5, 5), 20, dtype=np.uint8)                   # 5×5 회색 사진, 모든 칸 20
img[2, 2] = 255                                             # 가운데 한 칸만 255(소금 잡음)

print(cv2.blur(img, (3, 3))[1:4, 1:4])                      # 박스 필터 3×3, 가운데 3×3만 출력
print(cv2.GaussianBlur(img, (3, 3), 1)[1:4, 1:4])           # 가우시안 3×3, σ = 1
print(cv2.medianBlur(img, 3)[1:4, 1:4])                     # 중앙값 필터 3×3
```

```python
I = np.array([10, 10, 10, 60, 60, 60], dtype=np.float64)    # 경계가 있는 입력 줄
B = np.correlate(I, np.array([1, 1, 1]) / 3, "valid")       # 박스 필터로 흐림, 4칸
sharp = I[1:5] + (I[1:5] - B)                               # B와 같은 위치의 원본 4칸으로 샤프닝
print(np.clip(sharp, 0, 255).round())                       # 0~255로 자르고 반올림
```
