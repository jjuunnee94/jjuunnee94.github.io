## 1. GRU 구조
- LSTM을 단순화한 구조로, 상태는 **은닉 상태 $h$ 하나**만 사용
- 후보를 만든 뒤 **이전 은닉 상태와 섞어서** 새 상태를 만듦
- 게이트는 2개, 후보 상태는 1개

| 기호 | 이름 | 역할 | 활성화 |
|:---:|:---:|:---:|:---:|
| $r$ | 리셋 게이트 | 후보를 만들 때 이전 상태의 기여를 조절 | $\sigma$ |
| $z$ | 업데이트 게이트 | 이전 상태를 남길 비율 | $\sigma$ |
| $n$ | 후보 상태 | 이번에 새로 만든 후보 (−1 ~ 1) | tanh |

## 2. GRU 식
- 새 은닉 상태 = (남길 비율 × 이전 상태) + (받아들일 비율 × 후보)
- 리셋 게이트 $r$은 후보의 **상태항에만** 곱해짐
- $z$와 $(1-z)$의 합은 1

📐[공식]

$$r=\sigma(W_{ir}x_t+b_{ir}+W_{hr}h_{t-1}+b_{hr}), \qquad z=\sigma(W_{iz}x_t+b_{iz}+W_{hz}h_{t-1}+b_{hz})$$

$$n=\tanh\big(W_{in}x_t+b_{in}+r\odot(W_{hn}h_{t-1}+b_{hn})\big), \qquad h_t=(1-z)\odot n+z\odot h_{t-1}$$

- $x_t$: 현재 입력, $h_{t-1}$: 이전 은닉 상태, $\odot$: 같은 칸끼리 곱
- $W_{ir}$: 입력 → 리셋 게이트, $W_{hr}$: 이전 은닉 상태 → 리셋 게이트 (나머지도 같은 규칙)

📍[예시] $x_t=-0.4,\ h_{t-1}=0.5$ ($F=H=1$)
- 리셋 $r$: 입력 가중치 0.6, 편향 0.1, 상태 가중치 −0.3, 상태 편향 0
- 업데이트 $z$: 입력 가중치 0.4, 편향 −0.2, 상태 가중치 0.5, 상태 편향 0
- 후보 $n$: 입력 가중치 −0.7, 편향 0.2, 상태 가중치 0.8, 상태 편향 0.1

| 단계 | 계산 | 결과 |
|:---:|:---:|:---:|
| 리셋 게이트 $r$ | $\sigma(0.6\times(-0.4)+0.1+(-0.3)\times0.5)=\sigma(-0.29)$ | **0.428004** |
| 업데이트 게이트 $z$ | $\sigma(0.4\times(-0.4)+(-0.2)+0.5\times0.5)=\sigma(-0.11)$ | **0.472528** |
| 후보 $n$ | $\tanh(0.48+0.428004\times0.5)=\tanh(0.694002)$ | **0.600547** |
| 새 은닉 상태 $h_t$ | $0.472528\times0.5+0.527472\times0.600547=0.236264+0.316772$ | **0.553036** |

## 3. 업데이트 게이트 $z$의 효과
- $z$가 클수록 이전 기억이 오래 남고, 작을수록 새 내용으로 빨리 바뀜
- $z=1$이면 $h_t=h_{t-1}$이라 기울기가 줄지 않고 흐르는 길이 됨 (LSTM의 셀 상태 경로와 같은 원리)
- 상태가 여러 칸이면 **칸마다 $z$가 따로** 있어서 칸별로 남길지 바꿀지를 정함

📍[예시] $h_{t-1}=0.5,\ n=-0.3$

| $z$ | 계산 | 새 은닉 상태 $h_t$ |
|:---:|:---:|:---:|
| 1 | $1\times0.5+0\times(-0.3)$ | **0.5** |
| 0.7 | $0.7\times0.5+0.3\times(-0.3)$ | **0.26** |
| 0.2 | $0.2\times0.5+0.8\times(-0.3)$ | **−0.14** |
| 0 | $0\times0.5+1\times(-0.3)$ | **−0.3** |

## 4. nn.GRU의 반환값과 가중치
- 반환값: `output, h_n = gru(x)` → 셀 상태 $c_n$이 **없음** (LSTM은 `output, (h_n, c_n)`)
- `output`: 모든 시점의 은닉 상태, (B, T, H)
- `h_n`: 마지막 시점의 은닉 상태, (층×방향, B, H)
- 층 1개, 방향 1개이면 `output[:, -1, :]`와 `h_n[0]`이 같음
- 게이트 계산을 리셋 $r$, 업데이트 $z$, 후보 $n$ 순서로 **3묶음** 쌓음 (LSTM은 4묶음)
- 파라미터 수: $3(HF+H^2+2H)$, 같은 크기의 LSTM의 3/4

📍[예시] $F=1,\ H=2$

| 이름 | 모양 | 값 |
|:---:|:---:|:---:|
| `weight_ih_l0` | (3H, F) | (6, 1) |
| `weight_hh_l0` | (3H, H) | (6, 2) |
| `bias_ih_l0`, `bias_hh_l0` | (3H,) | (6,) 각각 |
| 파라미터 수 | $3(2+4+4)$ | **30** |

## 5. 💻 [코드]
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jjuunnee94/jjuunnee94.github.io/blob/main/notebooks/rnn_practice.ipynb)

```python
import torch                                       # 파이토치
from torch import nn                               # 신경망 모듈

torch.manual_seed(0)                               # 무작위 초기값 고정
gru = nn.GRU(1, 2, batch_first=True)               # 입력 1칸, 상태 2칸, 입력 모양 (B, T, F)
x = torch.tensor([[[0.5], [-0.3], [0.8]]])         # 예제 1개 × 시점 3개 × 입력 1칸, (1, 3, 1)
output, h_n = gru(x)                               # 모든 시점을 한 번에 계산
print(output.shape, h_n.shape)                     # 두 반환값의 모양

last = output[:, -1, :]                            # 마지막 시점의 은닉 상태, (1, 2)
print(last.shape, torch.allclose(last, h_n[0]))    # 모양, h_n과 같은 값인지
```
