### 1. 기본 RNN 기호 및 순전파 공식

#### 🔍[기호] 기본 RNN 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$t$** | **시점 번호** | 지금이 몇 번째 시점인지 ($1 \sim T$) |
| **$T$** | **전체 시점 수** | 입력창의 길이 (한 번에 읽는 시점의 개수) |
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 새로 들어온 입력 데이터 |
| **$h_0$** | **처음 은닉 상태** | 기억이 없는 출발점 (초기 상태를 주지 않으면 0) |
| **$h_{t-1}$** | **이전 은닉 상태** | 직전 시점($t-1$)까지 요약해 전달받은 기억(상태) |
| **$h_t$** | **현재 은닉 상태** | 이번 시점($t$)에 새롭게 갱신된 기억이자 다음 시점으로 넘길 값 |
| **$y_t$** | **실제 정답 (타깃)** | 이번 시점($t$)에서 모델이 맞혀야 하는 실제 정답값 |
| **$\hat{y}_t$** | **모델 예측값** | 현재 은닉 상태($h_t$)를 바탕으로 모델이 계산한 예측 결과 |
| **$a_t$** | **가중합** | 활성화 함수($\tanh$)를 적용하기 직전의 선형 결합 값 |
| **$\tanh$** | **하이퍼볼릭 탄젠트** | 값을 $-1 \sim +1$ 사이로 눌러 비선형성을 주는 활성화 함수 |
| **$W_{xh}$** | **입력 가중치** | 현재 입력($x_t$)이 은닉 상태에 미치는 중요도 |
| **$W_{hh}$** | **순환(상태) 가중치** | 이전 기억($h_{t-1}$)을 다음 시점으로 얼마나 전달할지 정하는 중요도 |
| **$W_{hy}$** | **출력 가중치** | 현재 은닉 상태($h_t$)로부터 최종 예측($\hat{y}_t$)을 뽑아내는 중요도 |
| **$b_h,\; b_y$** | **편향 (Bias)** | 은닉 상태 계산($b_h$)과 출력 계산($b_y$)에 각각 더해지는 기본 기준값 |
| **$L$** | **손실 (Loss)** | 예측값($\hat{y}_t$)과 실제 정답($y_t$) 사이의 오차 크기 |

#### 📍[공식] 기본 RNN 순전파와 손실

- **가중합 계산**
  $$a_t = W_{xh}x_t + W_{hh}h_{t-1} + b_h$$
  - **쓰이는 이유**: 현재 들어온 새 정보($x_t$)와 과거부터 이어진 기억($h_{t-1}$)을 각각의 중요도(가중치)에 맞게 하나로 합치기 위해 사용한다.

- **은닉 상태 업데이트**
  $$h_t = \tanh(a_t)$$
  - **쓰이는 이유**: 매 시점 가중치를 반복해서 곱할 때 순전파 값이 무한히 커지는 것을 막기 위해 출력을 $-1 \sim +1$ 사이로 가두고, 비선형성을 부여한다. (기울기 폭발까지 막아 주지는 못하므로 3절의 클리핑이 따로 필요하다.)

- **예측값 출력 및 손실 계산** (손실은 마지막 시점 $T$의 예측으로 계산)
  $$\hat{y}_T = W_{hy}h_T + b_y, \qquad L = \frac{1}{2}(\hat{y}_T - y_T)^2$$
  - **쓰이는 이유**: 마지막 은닉 상태로부터 최종 예측값을 도출하고, 정답과의 오차 크기를 측정해 학습 방향(기울기)을 정하기 위해 사용한다.

### 2. 역전파(BPTT)와 기울기

#### 🔍[기호] 역전파 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$\delta_t$** | **오차 신호** | 시점 $t$의 가중합($a_t$)이 변할 때 손실($L$)이 변하는 정도 ($\partial L / \partial a_t$) |
| **$1-h_t^2$** | **tanh의 미분값** | $\tanh$를 지나며 기울기가 줄어드는 비율 ($h_t$가 $\pm 1$에 가까울수록 0에 가까움) |
| **$W^T$** | **전치 행렬** | 행과 열을 바꾼 행렬 (기울기를 거꾸로 전달할 때 사용) |
| **$\odot$** | **원소곱** | 같은 칸끼리 1:1로 곱하는 연산 |
| **$\partial L / \partial W_{hh}$** | **순환 가중치의 기울기** | $W_{hh}$를 조금 바꿨을 때 손실($L$)이 변하는 정도 |

#### 📍[공식] 역전파 공식과 쓰이는 이유

- **마지막 시점의 오차 신호**
  $$\delta_T = \big(W_{hy}^{T}(\hat{y}_T - y_T)\big) \odot (1 - h_T^2)$$
  - **쓰이는 이유**: 출력 오차를 출력 가중치($W_{hy}$)를 거쳐 마지막 은닉 상태까지 되돌리고, $\tanh$의 미분값을 곱해 가중합 기준의 오차 신호로 바꾸기 위해 사용한다. (출력층 없이 $\hat{y}=h$이면 $(\hat{y}_T - y_T)\odot(1-h_T^2)$이 된다.)

- **이전 시점으로 오차 신호 전달** (손실이 마지막 시점에만 있을 때)
  $$\delta_{t-1} = (W_{hh}^{T}\delta_t) \odot (1 - h_{t-1}^2)$$
  - **쓰이는 이유**: 최종 손실이 과거 시점의 상태에 얼마나 민감한지 연쇄 법칙으로 거슬러 올라가며 계산하기 위해 사용한다. (이 과정에서 $W_{hh}$와 $(1 - h^2)$가 계속 곱해지며 기울기 소실이 발생한다.)

- **공유 가중치의 최종 기울기 합산**
  $$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \delta_t\, h_{t-1}^T, \qquad \frac{\partial L}{\partial W_{xh}} = \sum_{t=1}^{T} \delta_t\, x_t^T, \qquad \frac{\partial L}{\partial b_h} = \sum_{t=1}^{T} \delta_t$$
  - **쓰이는 이유**: 모든 시점이 같은 가중치를 공유하므로, 각 시점의 기여를 모두 더해 한 번에 업데이트하기 위해 사용한다.

- **원칙**: 한 경로로 이어진 기울기는 **곱하고**, 공유 가중치의 시점별 기여는 **더한다**.

### 3. 기울기 소실·폭발과 클리핑

#### 🔍[비교] 소실과 폭발

| 구분 | 조건 | 결과 | 대응 |
|:---:|:---:|:---|:---:|
| **기울기 소실** | 시점마다 곱해지는 인자의 크기가 1보다 작음 | 먼 과거로 갈수록 기울기가 0에 가까워져 앞쪽 정보를 학습하지 못함 | LSTM · GRU |
| **기울기 폭발** | 곱해지는 인자의 크기가 1보다 큼 | 기울기가 급격히 커져 학습이 불안정해지고 `NaN`이 발생 | 기울기 클리핑 |

📍[예시] 인자를 시점마다 10번 곱하면 ($T=10$)

- 인자 0.5: $0.5^{10} \approx 0.00098$ (거의 사라짐)
- 인자 1.5: $1.5^{10} \approx 57.7$ (급격히 커짐)

- **기울기 클리핑**: 기울기가 정해 둔 한계보다 크면 그 한계로 잘라 폭발을 막는 방법
- ⚠️ 클리핑은 폭발만 막을 뿐, 이미 사라진 신호를 되살리지는 못한다.
- ⚠️ 장기 의존(먼 과거가 필요한 문제)과 기울기 소실(학습 신호가 사라지는 현상)은 서로 다른 개념이다.

### 4. 학습 한 번의 순서

| 순서 | 단계 | 하는 일 |
|:---:|:---:|:---|
| **1** | **순전파 (forward)** | 입력을 넣어 예측값 $\hat{y}$ 계산 |
| **2** | **손실 계산** | 예측값과 정답의 오차 $L$ 계산 |
| **3** | **역전파 (backward)** | 기울기만 계산하고 가중치는 바꾸지 않음 |
| **4** | **`optimizer.step`** | 계산된 기울기로 가중치를 실제로 변경 |
