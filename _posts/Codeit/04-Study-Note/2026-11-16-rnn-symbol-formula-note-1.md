### 1. 모양 기호

#### 🔍[기호] 모양 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$B$** | **예제 수 (배치 크기)** | 한 번에 넣는 입력창의 개수 |
| **$T$** | **시점 수 (창 길이)** | 입력창의 길이 (몇 번 반복해서 읽는지) |
| **$F$** | **입력 칸 수** | 한 시점에 들어오는 숫자의 개수 |
| **$H$** | **상태 칸 수** | 은닉 상태(메모장)의 칸 수 |
| **$K$** | **층 수** | 쌓은 RNN 층의 개수 (`num_layers`) |
| **$D$** | **방향 수** | 단방향 1, 양방향 2 (양방향은 3편) |
| **$N$** | **전체 데이터 길이** | 시계열 전체의 점(날짜) 개수 |

⚠️[주의] 강의에서 창 길이로 쓰는 $L$은 손실 $L$(2절)과 겹치므로, 이 정리에서는 창 길이를 $T$로 쓴다.

### 2. 기본 RNN 기호 및 순전파 공식

#### 🔍[기호] 기본 RNN 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$t$** | **시점 번호** | 지금이 몇 번째 시점인지 ($1 \sim T$) |
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 새로 들어온 입력 데이터 |
| **$h_0$** | **처음 은닉 상태** | 기억이 없는 출발점 (초기 상태를 주지 않으면 0) |
| **$h_{t-1}$** | **이전 은닉 상태** | 직전 시점($t-1$)까지 요약해 전달받은 기억(상태) |
| **$h_t$** | **현재 은닉 상태** | 이번 시점($t$)에 새롭게 갱신된 기억이자 다음 시점으로 넘길 값 |
| **$y_t$** | **실제 정답 (타깃)** | 이번 시점($t$)에서 모델이 맞혀야 하는 실제 정답값 |
| **$\hat{y}_t$** | **모델 예측값** | 현재 은닉 상태($h_t$)를 바탕으로 모델이 계산한 예측 결과 |
| **$\tanh$** | **하이퍼볼릭 탄젠트** | 값을 $-1 \sim +1$ 사이로 눌러 비선형성을 주는 활성화 함수 |
| **$a_t$** | **가중합** | 활성화 함수($\tanh$)를 적용하기 직전의 선형 결합 값 |
| **$W_{xh}$** | **입력 가중치** | 현재 입력($x_t$)이 은닉 상태에 미치는 중요도 |
| **$W_{hh}$** | **순환(상태) 가중치** | 이전 기억($h_{t-1}$)을 다음 시점으로 얼마나 전달할지 정하는 중요도 |
| **$W_{hy}$** | **출력 가중치** | 현재 은닉 상태($h_t$)로부터 최종 예측($\hat{y}_t$)을 뽑아내는 중요도 |
| **$b_h,\; b_y$** | **편향 (Bias)** | 은닉 상태 계산($b_h$)과 출력 계산($b_y$)에 각각 더해지는 기본 기준값 |
| **$L$** | **손실 (Loss)** | 예측값($\hat{y}_t$)과 실제 정답($y_t$) 사이의 오차 크기 |

#### 📍[공식] 기본 RNN 순전파와 손실

- **가중합 계산**
  $$a_t = W_{xh}x_t + W_{hh}h_{t-1} + b_h$$
  - **쓰이는 이유**: 현재 들어온 새 정보($x_t$)와 과거부터 이어진 기억($h_{t-1}$)을 각각의 중요도(가중치)에 맞게 하나로 합치기 위해 사용한다.

- **은닉 상태 업데이트**
  $$h_t = \tanh(a_t)$$
  - **쓰이는 이유**: 매 시점 가중치를 반복해서 곱할 때 순전파 값이 무한히 커지는 것을 막기 위해 출력을 $-1 \sim +1$ 사이로 가두고, 비선형성을 부여한다. (기울기 폭발까지 막아 주지는 못하므로 2편의 클리핑이 따로 필요하다.)

- **예측값 출력 및 손실 계산** (손실은 마지막 시점 $T$의 예측으로 계산)
  $$\hat{y}_T = W_{hy}h_T + b_y, \qquad L = \frac{1}{2}(\hat{y}_T - y_T)^2$$
  - **쓰이는 이유**: 마지막 은닉 상태로부터 최종 예측값을 도출하고, 정답과의 오차 크기를 측정해 학습 방향(기울기: 가중치를 바꿨을 때 손실이 변하는 정도)을 정하기 위해 사용한다.

📍[예시] 한 시점의 모양 ($F$: 입력 칸 수, $H$: 상태 칸 수)

| 기호 | 모양 |
|:---:|:---:|
| **$x_t$** (현재 입력) | ($F$,) |
| **$h_{t-1},\; h_t$** (은닉 상태) | ($H$,) |
| **$W_{xh}$** (입력 가중치) | ($H$, $F$) |
| **$W_{hh}$** (순환 가중치) | ($H$, $H$) |
| **$b_h$** (편향) | ($H$,) |
| **$W_{hy}$** (출력 가중치) | (예측값 칸 수, $H$) |

### 3. 입출력 모양 규칙 (nn.RNN)

#### 📍[규칙] 입출력 모양 ($B$: 예제 수, $T$: 시점 수, $F$: 입력 칸 수, $H$: 상태 칸 수, $K$: 층 수, $D$: 방향 수)

- `batch_first=True`: 입력을 ($B$, $T$, $F$) 순서로 받겠다는 설정
- `output`: 모든 시점의 은닉 상태를 모은 값
- `h_n`: 마지막 시점의 은닉 상태

| 모듈 | 입력 | 반환값과 모양 |
|:---:|:---:|:---|
| **`nn.RNN`** | ($B$, $T$, $F$) | `output` ($B$, $T$, $D \cdot H$), `h_n` ($K \cdot D$, $B$, $H$) |
| **`nn.RNNCell`** (한 시점) | $x$: ($B$, $F$), $h$: ($B$, $H$) | 새 $h$: ($B$, $H$) |

- 이 정리의 예시는 한 층·단방향($K=1$, $D=1$)
- 한 층·단방향이면 `output[:, -1, :]` ($B$, $H$)와 `h_n[0]`이 같음 (시점 축 $T$가 사라짐)
- 초기 상태를 주지 않으면 호출마다 **처음 상태가 0**에서 시작
- 입력 길이 $T$가 달라져도 `h_n`과 가중치의 모양은 그대로이고 `output`의 $T$ 축만 바뀜
- 단방향에서는 앞쪽 시점의 출력이 입력이 길어져도 같고, **마지막 상태의 값**은 달라짐

### 4. 시계열 창과 예측층 모양

#### 📍[공식] 창 개수와 모양

- **창 개수**: 길이 $N$인 시계열을 창 길이 $T$로 자르고, 창 바로 다음 값을 정답으로 삼으면 창은 $N-T$개
- **입력** $X$: ($N-T$, $T$, $F$) ($F=1$이면 하루 값 1개), **정답** $y$: ($N-T$, 1)
- **예측층**: 마지막 시점의 은닉 상태 ($B$, $H$)를 `nn.Linear(H, 1)`(입력 $H$칸을 받아 1칸을 내놓는 층)에 넣어 예측 ($B$, 1)을 얻음
  $$\hat{y} = \sum_{j=1}^{H} w_j h_j + b$$
  - $w_j$: $j$번째 상태 칸의 가중치, $h_j$: 마지막 은닉 상태의 $j$번째 칸, $b$: 편향 (2절의 $W_{hy}$가 (1, $H$)인 경우와 같음)

📍[예시] $N=10$, $T=4$, $F=1$

| 항목 | 계산 | 결과 |
|:---:|:---:|:---:|
| **창 개수** | $10-4$ | **6** |
| **$X$ 모양** | ($N-T$, $T$, $F$) | **(6, 4, 1)** |
| **$y$ 모양** | ($N-T$, 1) | **(6, 1)** |
