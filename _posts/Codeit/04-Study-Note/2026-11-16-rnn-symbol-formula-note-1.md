### 1. 모양 기호

#### 🔍[기호] 모양 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$B$** | **예제 수 (배치 크기)** | 한 번에 넣는 입력창의 개수 |
| **$T$** | **시점 수 (창 길이)** | 입력창의 길이 (반복 횟수) |
| **$F$** | **입력 칸 수** | 한 시점에 들어오는 숫자(특성) 개수 |
| **$H$** | **상태 칸 수** | 은닉 상태(메모장)의 칸 수 |
| **$K$** | **층 수** | 쌓은 RNN 층의 개수 (`num_layers`) |
| **$D$** | **방향 수** | 단방향 1, 양방향 2 (양방향은 3편) |
| **$N$** | **전체 데이터 길이** | 시계열 전체의 점(날짜) 개수 |

⚠️[주의] 창 길이는 손실 $L$(2절)과 구분하기 위해 $T$로 표기한다.

### 2. 기본 RNN 기호 및 순전파 공식

#### 🔍[기호] 기본 RNN 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$t$** | **시점 번호** | 현재 시점 인덱스 ($1 \sim T$) |
| **$x_t$** | **현재 입력** | 시점 $t$에 새로 들어온 입력 데이터 |
| **$h_0$** | **처음 은닉 상태** | 초기 기억 (별도 지정 없으면 0) |
| **$h_{t-1}$** | **이전 은닉 상태** | 직전 시점($t-1$)에서 전달받은 기억 |
| **$h_t$** | **현재 은닉 상태** | 시점 $t$에서 갱신되어 다음으로 넘길 기억 |
| **$y_t$** | **실제 정답 (타깃)** | 시점 $t$의 실제 정답값 |
| **$\hat{y}_t$** | **모델 예측값** | 현재 은닉 상태($h_t$)로 계산한 예측 결과 |
| **$\tanh$** | **하이퍼볼릭 탄젠트** | 값을 $-1 \sim +1$ 사이로 눌러 비선형성을 주는 활성화 함수 |
| **$a_t$** | **가중합** | 활성화 함수($\tanh$) 적용 전 선형 결합 값 |
| **$W_{xh}$** | **입력 가중치** | 현재 입력($x_t$) → 은닉 상태 가중치 |
| **$W_{hh}$** | **순환(상태) 가중치** | 이전 기억($h_{t-1}$) → 현재 은닉 상태 가중치 |
| **$W_{hy}$** | **출력 가중치** | 현재 은닉 상태($h_t$) → 예측값($\hat{y}_t$) 가중치 |
| **$b_h,\; b_y$** | **편향 (Bias)** | 은닉 상태($b_h$) 및 출력($b_y$) 계산에 더해지는 편향 |
| **$L$** | **손실 (Loss)** | 예측값($\hat{y}_t$)과 실제 정답($y_t$)의 오차 크기 |

#### 📍[공식] 기본 RNN 순전파와 손실

- **가중합 계산**
  $$a_t = W_{xh}x_t + W_{hh}h_{t-1} + b_h$$
- **은닉 상태 업데이트** (출력을 $-1 \sim +1$로 제한해 순전파 값 발산 방지 및 비선형성 부여)
  $$h_t = \tanh(a_t)$$
- **예측값 출력 및 손실 계산** (마지막 시점 $T$ 기준)
  $$\hat{y}_T = W_{hy}h_T + b_y, \qquad L = \frac{1}{2}(\hat{y}_T - y_T)^2$$

📍[예시] 한 시점의 모양 ($F$: 입력 칸 수, $H$: 상태 칸 수)

| 기호 | 모양 |
|:---:|:---:|
| **$x_t$** (현재 입력) | ($F$,) |
| **$h_{t-1},\; h_t$** (은닉 상태) | ($H$,) |
| **$W_{xh}$** (입력 가중치) | ($H$, $F$) |
| **$W_{hh}$** (순환 가중치) | ($H$, $H$) |
| **$b_h$** (편향) | ($H$,) |
| **$W_{hy}$** (출력 가중치) | (예측값 칸 수, $H$) |

### 3. 입출력 모양 규칙 (`nn.RNN`)

#### 📍[규칙] 입출력 모양 ($B$: 예제 수, $T$: 시점 수, $F$: 입력 칸 수, $H$: 상태 칸 수, $K$: 층 수, $D$: 방향 수)

- `batch_first=True`: 입력 차원 순서를 ($B$, $T$, $F$)로 설정
- `output`: 모든 시점의 은닉 상태 모음 / `h_n`: 마지막 시점의 은닉 상태

| 모듈 | 입력 | 반환값과 모양 |
|:---:|:---:|:---|
| **`nn.RNN`** | ($B$, $T$, $F$) | `output` ($B$, $T$, $D \cdot H$), `h_n` ($K \cdot D$, $B$, $H$) |
| **`nn.RNNCell`** (한 시점) | $x$: ($B$, $F$), $h$: ($B$, $H$) | 새 $h$: ($B$, $H$) |

- 한 층·단방향($K=1, D=1$)일 때 `output[:, -1, :]` ($B$, $H$)와 `h_n[0]`은 동일
- 시점 길이 $T$가 변해도 `h_n`과 가중치 모양은 불변 (`output`의 $T$ 축만 변동)
- 단방향에서는 시퀀스 길이가 늘어나도 앞쪽 시점의 출력은 유지되고 마지막 상태만 변동

### 4. 시계열 창과 예측층 모양

#### 📍[공식] 창 개수와 모양

- **창 개수**: 길이 $N$인 시계열을 창 길이 $T$로 자르고 직후 값을 정답으로 삼을 때 **$N-T$개**
- **입력** $X$: ($N-T$, $T$, $F$) / **정답** $y$: ($N-T$, 1)
- **예측층**: 마지막 은닉 상태 ($B$, $H$)를 `nn.Linear(H, 1)`에 통과시켜 예측 ($B$, 1) 도출
  $$\hat{y} = \sum_{j=1}^{H} w_j h_j + b$$
  - $w_j$: $j$번째 상태 칸 가중치, $h_j$: 마지막 은닉 상태의 $j$번째 칸, $b$: 편향 (2절의 $W_{hy}$가 $(1, H)$인 경우)

📍[예시] $N=10$, $T=4$, $F=1$

| 항목 | 계산 | 결과 |
|:---:|:---:|:---:|
| **창 개수** | $10-4$ | **6** |
| **$X$ 모양** | ($N-T$, $T$, $F$) | **(6, 4, 1)** |
| **$y$ 모양** | ($N-T$, 1) | **(6, 1)** |
