#### 🔍[기호] 컴퓨터 비전 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---:|
| **H** | **높이(세로 칸 수)** | 이미지의 세로 픽셀 수 (배열의 행 수) |
| **W** | **너비(가로 칸 수)** | 이미지의 가로 픽셀 수 (배열의 열 수) |
| **C** | **채널 수** | 픽셀마다 모은 값의 수 (RGB 컬러 = 3, 회색 = 1) |
| **N** | **이미지 수(배치 크기)** | 한 번에 모델에 넣는 이미지 수 |
| **R, G, B** | **빨강, 초록, 파랑 값** | 한 픽셀의 채널 값 (0~255 정수) |
| **Y** | **밝기 성분(luma)** | 회색 변환 결과 |
| **x** | **픽셀 값** | 정규화 전 값 (0~255) |
| **x′** | **정규화 값** | 정규화 후 값 (0~1) |

#### 📍[공식] 회색 변환 · uint8 · 정규화

- **회색 변환** (컬러 → 밝기 한 장)
  - 밝기 Y = 0.299 × 빨강 R + 0.587 × 초록 G + 0.114 × 파랑 B

$$Y = 0.299R + 0.587G + 0.114B$$

- **uint8 오버플로** (0~255를 넘으면 256으로 나눈 나머지)
  - 결과 = (a + b)를 256으로 나눈 나머지

$$(a + b) \bmod 256$$

- **정규화** (0~255 → 0~1)
  - 정규화 값 x′ = 픽셀 값 x ÷ 255

$$x' = \frac{x}{255}$$

#### 📍[공식] 이미지 모양 규칙

- NumPy 배열: `(H, W, C)` = (높이, 너비, 채널 수)
- Pillow `size`: `(W, H)` = (너비, 높이), 배열과 순서가 반대
- Conv2d 입력 텐서: `[N, C, H, W]`
- 축 순서 변환: `permute(2, 0, 1)` = (H, W, C) → (C, H, W)

#### 🔍[비교] 색공간 · 축 · 쓰는 곳

| 색공간 | 축 | 쓰는 곳 |
|:---:|:---:|:---:|
| **RGB** | 빨강, 초록, 파랑 | 화면 표시, 파일 |
| **HSV** | 색상, 채도, 명도 | 색 범위로 영역 선택 |
| **YCbCr** | 밝기 Y, 색차 Cb·Cr | JPEG 압축 |
