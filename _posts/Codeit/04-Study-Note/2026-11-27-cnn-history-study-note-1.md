## 1. 시각 피질 연구 (1959~1962)

| 연도 | 사건 | 내용 | 구분 |
|:---:|:---:|:---:|:---:|
| 1959 | 허벨(Hubel)과 비즐(Wiesel)의 고양이 실험 | 마취한 고양이의 1차 시각 피질에 전극을 꽂고 이미지를 보여 주며 뉴런 반응을 관찰 | 슬라이드에 없음 |
| 1962 | 고양이 시각 피질 체계적 연구 | 뉴런 하나가 시야의 작은 영역만 처리한다는 수용장(receptive field) 개념 제시 | 슬라이드에 없음 |
| 1981 | 노벨 생리의학상 | 두 사람이 공동 수상자에 포함 | 슬라이드에 없음 |

- 단순 세포(simple cell): 특정 위치의 특정 방향 막대·모서리에 반응
- 복잡 세포(complex cell): 같은 방향을 선호하는 여러 단순 세포의 입력을 받음
- 시각 처리는 모서리 같은 단순한 구조에서 시작해 점점 복잡한 구조로 올라가는 계층 구조
- 슬라이드의 "시각 피질의 작동 방식에서 영감을 받은 인공 신경망"이라는 문장이 이 연구와 연결됨

## 2. 네오코그니트론 (1979~1980)

| 항목 | 내용 |
|:---:|:---:|
| 제안자 | 후쿠시마 쿠니히코(Kunihiko Fukushima) |
| 발표 | 1979년 일본어 논문, 1980년 학술지 Biological Cybernetics |
| 목표 | 위치가 옮겨져도 영향받지 않는 패턴 인식 |
| 구조 | 단순 세포형 층(S층)과 복잡 세포형 층(C층)을 번갈아 쌓음 |
| 학습 | 자기조직화(self-organization) 방식 |

- 합성곱층과 다운샘플링층이 처음 등장한 모델로 평가됨
- 이전 모델들(코그니트론 등)은 입력 패턴의 위치 이동과 모양 변형에 크게 흔들렸음
- 현대 CNN의 원형이지만, 오차 역전파로 학습하는 구조는 아님

## 3. 역전파를 CNN에 적용 (1988~1998)

| 연도 | 사건 | 내용 | 구분 |
|:---:|:---:|:---:|:---:|
| 1988 | 장웨이(Wei Zhang) 외 | 단순화한 네오코그니트론에 역전파를 적용해 알파벳 인식 | 슬라이드에 없음 |
| 1989 | 얀 르쿤(Yann LeCun) 외 | CNN으로 우편물의 손글씨 우편번호 인식 | 슬라이드에 없음 |
| 1998 | LeNet-5 | 7개 층, 32×32 크기 숫자 이미지 분류, 은행에서 수표의 손글씨 숫자 인식에 활용 | LeNet은 슬라이드에 있음 |

- 슬라이드의 LeNet 설명: 딥러닝 연구의 벤치마크 데이터셋을 제시했고, 이미지 인식 정확도 98% 이상
- 슬라이드의 LeNet은 논문 "Gradient-based learning applied to document recognition"(1998)

## 4. 정리한 흐름

| 1980 | 네오코그니트론 | 자기조직화 | 합성곱·다운샘플링 구조의 원형 |
| 1988~1989 | 장웨이, 르쿤 | 역전파 | CNN을 역전파로 학습 |
