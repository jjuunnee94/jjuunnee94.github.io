## 1. ILSVRC란

- 이미지넷 대규모 시각 인식 대회(ILSVRC): 수백만 장의 이미지와 1000여 개 클래스를 다루는 이미지 분류·객체 검출 대회
- 2010년부터 매년 열린 대회로, 모든 팀이 같은 데이터로 학습하고 같은 테스트 데이터로 점수를 받음
- 평가 지표 top-5 오류율: 정답 라벨이 모델이 고른 확률 상위 5개에 들지 못한 테스트 이미지의 비율

## 2. 우승 모델의 오류율 추이

| 연도 | 우승 모델 | top-5 오류율 | 층 수 |
|:---:|:---:|:---:|:---:|
| 2012 이전 | 전통 머신러닝(SVM 등) | 약 26% | - |
| 2012 | AlexNet | 약 16% (논문 기준 15.3%) | 8 |
| 2013 | ZFNet(Clarifai) | 11.7% | - |
| 2014 | GoogLeNet | 6.7% | 22 |
| 2015 | ResNet | 3.6% (논문 기준 3.57%) | 152 |
| 2016 | (우승 모델명 확인하지 못함) | 2.991% | - |
| 2017 | SENet | 2.251% | - |

- VGGNet은 2014년 분류 2위로, 오류율은 약 7.3%
- 사람의 오류율은 5.1% 이고, 2015년 ResNet이 처음으로 이보다 낮아짐
- 2012년 2위 팀의 오류율은 26.2%로, AlexNet과의 격차가 컸음
- 2017년 SENet은 2016년 우승 기록 대비 약 25% 상대 개선
- AlexNet 오류율은 모델 구성(단일 모델, 앙상블)에 따라 논문 안에서도 15.3~16.4%로 다름

## 3. 앞 모델의 한계와 다음 모델의 해결책

| 모델 | 앞 모델의 한계 | 해결 방식 |
|:---:|:---:|:---:|
| AlexNet | 전통 머신러닝·얕은 구조는 오류율 약 26%에서 정체 | 깊은 CNN, GPU 학습, ReLU, 드롭아웃, 데이터 증강 |
| VGGNet | AlexNet은 층 수가 적고 필터 크기가 제각각 | 3×3 필터를 반복해 깊이를 늘려 성능 향상 |
| GoogLeNet | 층을 늘리면 연산량과 파라미터 수가 급격히 증가 | 인셉션 모듈, 1×1 합성곱으로 채널 축소, 완전연결층 제거 |
| ResNet | 층을 더 쌓는다고 학습이 쉬워지지 않음 | 잔차 학습과 스킵 연결로 기울기 소실 문제 해결 |
