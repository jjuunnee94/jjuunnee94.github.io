### 1. 기본 RNN 기호 및 핵심 공식

#### 🔍[기호] 기본 RNN 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 새로 들어온 입력 데이터 |
| **$h_{t-1}$** | **이전 은닉 상태** | 직전 시점($t-1$)까지 요약해 전달받은 기억(상태) |
| **$h_t$** | **현재 은닉 상태** | 이번 시점($t$)에 새롭게 갱신된 기억이자 다음 시점으로 넘길 값 |
| **$y_t$** | **실제 정답 (타깃)** | 이번 시점($t$)에서 모델이 맞혀야 하는 실제 정답값 |
| **$\hat{y}_t$** | **모델 예측값** | 현재 은닉 상태($h_t$)를 바탕으로 모델이 계산한 예측 결과 |
| **$a_t$** | **가중합** | 활성화 함수($\tanh$)를 적용하기 직전의 선형 결합 값 |
| **$\tanh$** | **하이퍼볼릭 탄젠트** | 값을 $-1 \sim +1$ 사이로 눌러 비선형성을 주는 활성화 함수 |
| **$W_{xh}$** | **입력 가중치** | 현재 입력($x_t$)이 은닉 상태에 미치는 중요도 |
| **$W_{hh}$** | **순환(상태) 가중치** | 이전 기억($h_{t-1}$)을 다음 시점으로 얼마나 전달할지 정하는 중요도 |
| **$W_{hy}$** | **출력 가중치** | 현재 은닉 상태($h_t$)로부터 최종 예측($\hat{y}_t$)을 뽑아내는 중요도 |
| **$b_h,\; b_y$** | **편향 (Bias)** | 은닉 상태 계산($b_h$)과 출력 계산($b_y$)에 각각 더해지는 기본 기준값 |
| **$L$** | **손실 (Loss)** | 예측값($\hat{y}_t$)과 실제 정답($y_t$) 사이의 오차 크기 |

#### 📍[공식] 기본 RNN 순전파 · 역전파(BPTT) 공식과 쓰이는 이유

- **가중합 계산 (Linear Combination)**
  $$a_t = W_{xh}x_t + W_{hh}h_{t-1} + b_h$$
  - **쓰이는 이유**: 현재 들어온 새 정보($x_t$)와 과거부터 이어진 기억($h_{t-1}$)을 각각의 중요도(가중치)에 맞게 하나로 합치기 위해 사용한다.

- **은닉 상태 업데이트 (Hidden State)**
  $$h_t = \tanh(a_t)$$
  - **쓰이는 이유**: 매 시점 가중치를 반복해서 곱할 때 값이 무한히 폭발(`NaN`)하는 것을 막기 위해 출력을 $-1 \sim +1$ 사이로 가두고, 신경망이 복잡한 문맥을 학습할 수 있도록 비선형성을 부여한다.

- **예측값 출력 및 손실 계산 (Output & Loss)**
  $$\hat{y}_t = W_{hy}h_t + b_y, \qquad L = \frac{1}{2}(\hat{y}_t - y_t)^2$$
  - **쓰이는 이유**: 현재 은닉 상태로부터 최종 예측값을 도출하고, 정답과의 오차 크기를 측정해 학습 방향(기울기)을 정하기 위해 사용한다.

- **이전 시점 영향도 전달 (BPTT Chain Rule)**
  $$\delta_t = (\hat{y}_t - y_t) \odot (1 - h_t^2), \qquad \delta_{t-1} = (W_{hh}^T \delta_t) \odot (1 - h_{t-1}^2)$$
  - **쓰이는 이유**: 최종 손실 오차가 과거 시점의 은닉 상태에 얼마나 민감하게 영향을 받는지 연쇄 법칙으로 거슬러 올라가며 계산하기 위해 사용한다. (이 과정에서 $W_{hh}$와 $(1 - h^2)$가 계속 곱해지며 기울기 소실이 발생한다.)

- **순환 가중치 최종 기울기 합산 (Total Gradient)**
  $$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \delta_t \cdot h_{t-1}^T$$
  - **쓰이는 이유**: 모든 시점에서 동일한 가중치 $W_{hh}$를 공유하므로, 각 시점에서 발생한 가중치 기여도($\delta_t \cdot h_{t-1}^T$)를 모두 더해 한 번에 업데이트하기 위해 사용한다.

### 2. LSTM(장단기 메모리) 기호 및 핵심 공식

#### 🔍[기호] LSTM 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 들어온 값 |
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | 직전 시점이 밖으로 내놓은 특징(단기 기억) 및 이번 시점의 최종 출력 |
| **$c_{t-1},\; c_t$** | **이전 / 현재 셀 상태** | 직전 시점까지 컨베이어 벨트에 저장해 둔 장기 기억 및 갱신된 장기 기억 |
| **$f$** | **망각 게이트 (Forget gate)** | 이전 셀 상태($c_{t-1}$)에서 남길 비율 ($0 \sim 1$) |
| **$i$** | **입력 게이트 (Input gate)** | 새 후보($g$)를 장기 기억에 반영할 비율 ($0 \sim 1$) |
| **$g$** | **새 기억 후보 (Candidate)** | 이번에 새로 저장할 후보 내용 ($-1 \sim +1$) |
| **$o$** | **출력 게이트 (Output gate)** | 완성된 셀 상태($c_t$)를 은닉 출력($h_t$)에 반영할 비율 ($0 \sim 1$) |
| **$a_q$** | **가중합** | 활성화를 적용하기 전 값 ($q$는 $i,\; f,\; g,\; o$ 중 하나) |
| **$\sigma$** | **시그모이드 (Sigmoid)** | 값을 $0 \sim 1$ 사이로 눌러 문(Gate)의 개폐 비율을 만드는 함수 |
| **$\odot$** | **원소곱 (아다마르 곱)** | 행렬/벡터의 같은 칸끼리 1:1로 곱하는 연산 |
| **$W_x,\; W_h,\; b$** | **입력/상태 가중치, 편향** | 각 경로($i,\; f,\; g,\; o$)가 독립적으로 가지는 학습 파라미터 |

#### 📍[공식] LSTM 순전파 공식과 쓰이는 이유

- **망각 게이트 (Forget Gate)**
  $$f = \sigma(a_f) = \sigma(W_{xf}x_t + W_{hf}h_{t-1} + b_f)$$
  - **쓰이는 이유**: 과거 장기 기억($c_{t-1}$) 중에서 더 이상 필요 없는 정보는 지우고(`0`에 가깝게), 계속 유지할 정보만 남기기(`1`에 가깝게) 위해 비율을 계산한다.

- **입력 게이트 및 새 기억 후보 (Input Gate & Candidate)**
  $$i = \sigma(a_i) = \sigma(W_{xi}x_t + W_{hi}h_{t-1} + b_i), \qquad g = \tanh(a_g) = \tanh(W_{xg}x_t + W_{hg}h_{t-1} + b_g)$$
  - **쓰이는 이유**: 현재 입력으로부터 장기 기억에 새로 기록할 후보 내용($g$)을 생성하고, 이 후보 중 중요한 부분만 골라 반영할 비율($i$)을 결정하기 위해 사용한다.

- **셀 상태 업데이트 (Cell State Update)**
  $$c_t = \underbrace{(f \odot c_{t-1})}_{\text{보존분}} + \underbrace{(i \odot g)}_{\text{새 기억 추가분}}$$
  - **쓰이는 이유**: 가중치 행렬 곱셈 없이 원소곱($\odot$)과 덧셈($+$)만으로 장기 기억을 갱신하여, 역전파 시 기울기가 소실되지 않고 문장 맨 앞까지 직통으로 전달되도록 하기 위해 사용한다.

- **출력 게이트 및 은닉 상태 출력 (Output Gate & Hidden State)**
  $$o = \sigma(a_o) = \sigma(W_{xo}x_t + W_{ho}h_{t-1} + b_o), \qquad h_t = o \odot \tanh(c_t)$$
  - **쓰이는 이유**: 장기 기억 전체($c_t$)를 그대로 노출하지 않고 $\tanh$로 값을 다듬은 뒤, 현재 시점의 예측에 당장 필요한 부분만 출력 비율($o$)만큼 걸러내 단기 기억($h_t$)으로 내보내기 위해 사용한다.

### 3. LSTM 극단 상황 검증 (기억 초기화 원리)

📍[예시] 과거 기억이 완전히 지워지고($f=0$) 장기 기억이 비어 있을 때($c_t=0$)의 동작

- **1단계: 과거 기억 완전 삭제 ($f=0$)**
  $$f = 0 \implies \text{보존분} = 0 \odot c_{t-1} = 0 \implies c_t = i \odot g$$
  - 망각 게이트($f$)가 `0`이 되면 이전 셀 상태($c_{t-1}$)가 모두 삭제되어, 오직 새로 들어온 기억($i \odot g$)만 남는다.

- **2단계: 장기 기억이 비어 있을 때 출력 검증 ($c_t=0$)**
  $$c_t = 0 \implies h_t = o \odot \tanh(0) = o \times 0 = 0$$
  - $\tanh(0) = 0$이므로 장기 기억 창고($c_t$)가 비어 있으면 출력 게이트($o$)의 값과 상관없이 은닉 상태($h_t$)도 자동으로 `0`으로 리셋된다. 이를 통해 기억이 없을 때 가짜 신호가 밖으로 새어 나가는 것을 방지한다.
