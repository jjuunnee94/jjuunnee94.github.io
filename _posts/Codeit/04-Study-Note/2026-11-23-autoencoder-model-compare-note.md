#### 🔍[비교] 모델 · 입력 · 구조 · 목적

| **모델** | **학습 입력** | **구조** | **잠재 표현 z** | **학습 목적** |
|:---:|:---:|:---:|:---:|:---:|
| **기본 AE** | 원본 x | 기준 | 결정값 | 원본 재구성 |
| **DAE** | 노이즈 입력 | CNN, 4×14×14 | 결정값 | 깨끗한 원본 재구성 |
| **Sparse AE** | 원본 x | 완전연결, 64 | 대부분 0 근처 | 재구성 + 희소 벌점 |
| **VAE** | 원본 x | 완전연결, 16 | 분포에서 뽑은 값 | 재구성 + KL |

- 구조·입력·목적이 달라 평균제곱오차(MSE) 값을 모델끼리 직접 비교하지 않음

#### 🔍[비교] 모델 · 핵심 장치 · 확인한 것

| **모델** | **핵심 장치** | **확인한 것** |
|:---:|:---:|:---:|
| **DAE** | 노이즈 입력 → 깨끗한 타깃 | 검증 10,000장 모두 MSE 감소 |
| **Sparse AE** | 복원 + λ × 평균 \|z\| | λ가 커지면 활성 비율 감소 |
| **VAE** | 분포 q · KL · prior | 복원과 생성, 잠재공간 관찰 |

#### 🔍[기호] 비교에 쓰는 기호 · 이름 · 뜻

| **기호** | **이름** | **뜻** |
|:---:|:---:|:---:|
| $\tilde{x}$ | **노이즈 입력** | 원본에 노이즈를 더한 입력 |
| $\lambda$ | **희소 규제 가중치** | 희소 벌점의 크기 |
| $z$ | **잠재 표현** | 인코더 출력 |
| KL | **KL 비용** | 분포 q와 prior의 차이 |

#### 📍[공식] 모델별 손실

- **기본 AE** (평균제곱오차(복원값, 원본))
$$L=\text{MSE}(\hat{x},\,x)$$

- **DAE** (평균제곱오차(노이즈 입력의 복원값, 깨끗한 원본))
$$L=\text{MSE}\big(D(E(\tilde{x})),\,x\big)$$

- **Sparse AE** (평균제곱오차 + 희소 규제 가중치 × 잠재 표현 절댓값의 평균)
$$L=\text{MSE}+\lambda\,\text{mean}(\lvert z\rvert)$$

- **VAE** (재구성 비용 + KL 비용)
$$L=L_{recon}+\text{KL}$$
