### 1. 학습 한 번의 순서

| 순서 | 단계 | 하는 일 |
|:---:|:---:|:---|
| **1** | **순전파 (forward)** | 입력을 넣어 예측값 $\hat{y}$ 계산 (1편 2절) |
| **2** | **손실 계산** | 예측값과 정답의 오차 $L$ 계산 |
| **3** | **역전파 (backward)** | 기울기(가중치를 바꿨을 때 손실이 변하는 정도)만 계산하고 가중치는 바꾸지 않음 |
| **4** | **`optimizer.step`** | 계산된 기울기로 가중치를 실제로 변경 |

### 2. 역전파(BPTT) 기호 및 공식

- **BPTT**: 시간을 거슬러 올라가며 하는 역전파 (3번 단계의 계산)

#### 🔍[기호] 역전파 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$\delta_t$** | **오차 신호** | 시점 $t$의 가중합($a_t$)이 변할 때 손실($L$)이 변하는 정도 ($\partial L / \partial a_t$) |
| **$1-h_t^2$** | **tanh의 미분값** | $\tanh$를 지나며 기울기가 줄어드는 비율 ($h_t$가 $\pm 1$에 가까울수록 0에 가까움) |
| **$W^T$** | **전치 행렬** | 행과 열을 바꾼 행렬 (기울기를 거꾸로 전달할 때 사용) |
| **$\odot$** | **원소곱** | 같은 칸끼리 1:1로 곱하는 연산 |
| **$\partial L / \partial W_{hh}$** | **순환 가중치의 기울기** | $W_{hh}$를 조금 바꿨을 때 손실($L$)이 변하는 정도 |

#### 📍[공식] 역전파 공식과 쓰이는 이유

- **마지막 시점의 오차 신호**
  $$\delta_T = \big(W_{hy}^{T}(\hat{y}_T - y_T)\big) \odot (1 - h_T^2)$$
  - **쓰이는 이유**: 출력 오차를 출력 가중치($W_{hy}$)를 거쳐 마지막 은닉 상태까지 되돌리고, $\tanh$의 미분값을 곱해 가중합 기준의 오차 신호로 바꾸기 위해 사용한다. (출력층 없이 $\hat{y}=h$이면 $(\hat{y}_T - y_T)\odot(1-h_T^2)$이 된다.)

- **이전 시점으로 오차 신호 전달** (손실이 마지막 시점에만 있을 때)
  $$\delta_{t-1} = (W_{hh}^{T}\delta_t) \odot (1 - h_{t-1}^2)$$
  - **쓰이는 이유**: 최종 손실이 과거 시점의 상태에 얼마나 민감한지 연쇄 법칙으로 거슬러 올라가며 계산하기 위해 사용한다. (이 과정에서 $W_{hh}$와 $(1 - h^2)$가 계속 곱해지며 기울기 소실이 발생한다.)

- **공유 가중치의 최종 기울기 합산**
  $$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \delta_t\, h_{t-1}^T, \qquad \frac{\partial L}{\partial W_{xh}} = \sum_{t=1}^{T} \delta_t\, x_t^T, \qquad \frac{\partial L}{\partial b_h} = \sum_{t=1}^{T} \delta_t$$
  - **쓰이는 이유**: 모든 시점이 같은 가중치를 공유하므로, 각 시점의 기여를 모두 더해 한 번에 업데이트하기 위해 사용한다.

- **원칙**: 한 경로로 이어진 기울기는 **곱하고**, 공유 가중치의 시점별 기여는 **더한다**.

### 3. 기울기 소실·폭발과 클리핑

#### 🔍[비교] 소실과 폭발

| 구분 | 조건 | 결과 | 대응 |
|:---:|:---:|:---|:---:|
| **기울기 소실** | 시점마다 곱해지는 인자의 크기가 1보다 작음 | 먼 과거로 갈수록 기울기가 0에 가까워져 앞쪽 정보를 학습하지 못함 | LSTM (4절), GRU (3편) |
| **기울기 폭발** | 곱해지는 인자의 크기가 1보다 큼 | 기울기가 급격히 커져 학습이 불안정해지고 `NaN`(숫자가 아님)이 발생 | 기울기 클리핑 |

📍[예시] 인자(예: $W_{hh}(1-h^2)$)를 시점마다 10번 곱하면 ($T=10$)

- 인자 0.5: $0.5^{10} \approx 0.00098$ (거의 사라짐)
- 인자 1.5: $1.5^{10} \approx 57.7$ (급격히 커짐)

- **기울기 클리핑**: 기울기가 정해 둔 한계보다 크면 그 한계로 잘라 폭발을 막는 방법
- ⚠️ 클리핑은 폭발만 막을 뿐, 이미 사라진 신호를 되살리지는 못한다.
- ⚠️ 장기 의존(먼 과거가 필요한 문제)과 기울기 소실(학습 신호가 사라지는 현상)은 서로 다른 개념이다.

### 4. LSTM(장단기 메모리) 기호 및 공식

#### 🔍[기호] LSTM 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 들어온 값 |
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | 직전 시점이 밖으로 내놓은 특징(단기 기억) 및 이번 시점의 최종 출력 |
| **$c_{t-1},\; c_t$** | **이전 / 현재 셀 상태** | 직전 시점까지 컨베이어 벨트에 저장해 둔 장기 기억 및 갱신된 장기 기억 |
| **$f$** | **망각 게이트 (Forget gate)** | 이전 셀 상태($c_{t-1}$)에서 남길 비율 ($0 \sim 1$) |
| **$i$** | **입력 게이트 (Input gate)** | 새 기억 후보(다음 행의 $g$)를 장기 기억에 반영할 비율 ($0 \sim 1$) |
| **$g$** | **새 기억 후보 (Candidate)** | 이번에 새로 저장할 후보 내용 ($-1 \sim +1$) |
| **$o$** | **출력 게이트 (Output gate)** | 완성된 셀 상태($c_t$)를 은닉 출력($h_t$)에 반영할 비율 ($0 \sim 1$) |
| **$a_q$** | **가중합** | 활성화를 적용하기 전 값 ($q$는 $i,\; f,\; g,\; o$ 중 하나) |
| **$\sigma$** | **시그모이드 (Sigmoid)** | 값을 $0 \sim 1$ 사이로 눌러 문(Gate)의 개폐 비율을 만드는 함수 |
| **$W_x,\; W_h,\; b$** | **입력/상태 가중치, 편향** | 각 경로($i,\; f,\; g,\; o$)가 독립적으로 가지는 학습 파라미터 |
| **$\Delta c$** | **셀 상태 변화량** | 망각 게이트 비율($f$)이 변했을 때 달라지는 장기 기억의 차이값 |

#### 📍[공식] LSTM 순전파 공식과 쓰이는 이유

- **망각 게이트**
  $$f = \sigma(a_f) = \sigma(W_{xf}x_t + W_{hf}h_{t-1} + b_f)$$
  - **쓰이는 이유**: 과거 장기 기억($c_{t-1}$) 중에서 필요 없는 정보는 지우고(`0`에 가깝게), 유지할 정보만 남기기(`1`에 가깝게) 위해 비율을 계산한다.

- **입력 게이트 및 새 기억 후보**
  $$i = \sigma(a_i) = \sigma(W_{xi}x_t + W_{hi}h_{t-1} + b_i), \qquad g = \tanh(a_g) = \tanh(W_{xg}x_t + W_{hg}h_{t-1} + b_g)$$
  - **쓰이는 이유**: 현재 입력으로부터 장기 기억에 새로 기록할 후보 내용($g$)을 만들고, 그중 얼마나 반영할지 비율($i$)을 정하기 위해 사용한다.

- **셀 상태 업데이트**
  $$c_t = \underbrace{(f \odot c_{t-1})}_{\text{보존분}} + \underbrace{(i \odot g)}_{\text{새 기억 추가분}}$$
  - **쓰이는 이유**: 가중치 행렬 곱 없이 원소곱($\odot$)과 덧셈($+$)만으로 장기 기억을 갱신한다. 셀 상태를 직접 지나는 경로에는 $f$만 곱해지므로, $f$가 1에 가까우면 기울기가 거의 줄지 않고 과거까지 전달된다.

- **망각 게이트 변화에 따른 셀 상태 변화량**
  $$\Delta c = (f_{\text{새}} - f_{\text{기준}}) \odot c_{t-1}$$
  - **쓰이는 이유**: 다른 조건($i, g$)이 같을 때 $f$를 조절하면 장기 기억($c_t$)이 실제로 얼마나 변하는지($\Delta c = c_{\text{새}} - c_{\text{기준}}$) 확인하기 위해 사용한다.

- **출력 게이트 및 은닉 상태 출력**
  $$o = \sigma(a_o) = \sigma(W_{xo}x_t + W_{ho}h_{t-1} + b_o), \qquad h_t = o \odot \tanh(c_t)$$
  - **쓰이는 이유**: 장기 기억 전체($c_t$)를 그대로 노출하지 않고 $\tanh$로 다듬은 뒤, 현재 예측에 필요한 부분만 출력 비율($o$)만큼 걸러 단기 기억($h_t$)으로 내보내기 위해 사용한다.

### 5. LSTM 극단 상황 검증

📍[예시] 게이트 값이 0일 때의 동작 (세 가지는 서로 독립된 조건)

- **1단계: 과거 기억 완전 삭제 ($f=0$)**
  $$f = 0 \implies f \odot c_{t-1} = 0 \implies c_t = i \odot g$$
  - 이전 셀 상태($c_{t-1}$)가 모두 지워지고 새로 들어온 기억($i \odot g$)만 남는다.

- **2단계: 장기 기억이 비어 있을 때 ($c_t=0$)**
  $$c_t = 0 \implies h_t = o \odot \tanh(0) = 0$$
  - $\tanh(0)=0$이므로 출력 게이트($o$) 값과 상관없이 $h_t$도 `0`이 된다. ($f=0$만으로는 $c_t=0$이 되지 않고, $i \odot g$도 0이어야 한다.)

- **3단계: 출력 게이트 닫힘 ($o=0$)**
  $$o = 0 \implies h_t = 0, \quad c_t \text{는 그대로}$$
  - 출력 게이트는 밖으로 내보내는 양만 조절하고 셀 상태는 바꾸지 않는다.
