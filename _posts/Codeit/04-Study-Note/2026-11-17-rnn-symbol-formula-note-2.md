### 1. LSTM(장단기 메모리) 기호 및 공식

#### 🔍[기호] LSTM 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 들어온 값 |
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | 직전 시점이 밖으로 내놓은 특징(단기 기억) 및 이번 시점의 최종 출력 |
| **$c_{t-1},\; c_t$** | **이전 / 현재 셀 상태** | 직전 시점까지 컨베이어 벨트에 저장해 둔 장기 기억 및 갱신된 장기 기억 |
| **$f$** | **망각 게이트 (Forget gate)** | 이전 셀 상태($c_{t-1}$)에서 남길 비율 ($0 \sim 1$) |
| **$i$** | **입력 게이트 (Input gate)** | 새 후보($g$)를 장기 기억에 반영할 비율 ($0 \sim 1$) |
| **$g$** | **새 기억 후보 (Candidate)** | 이번에 새로 저장할 후보 내용 ($-1 \sim +1$) |
| **$o$** | **출력 게이트 (Output gate)** | 완성된 셀 상태($c_t$)를 은닉 출력($h_t$)에 반영할 비율 ($0 \sim 1$) |
| **$a_q$** | **가중합** | 활성화를 적용하기 전 값 ($q$는 $i,\; f,\; g,\; o$ 중 하나) |
| **$\sigma$** | **시그모이드 (Sigmoid)** | 값을 $0 \sim 1$ 사이로 눌러 문(Gate)의 개폐 비율을 만드는 함수 |
| **$\odot$** | **원소곱 (아다마르 곱)** | 행렬/벡터의 같은 칸끼리 1:1로 곱하는 연산 |
| **$W_x,\; W_h,\; b$** | **입력/상태 가중치, 편향** | 각 경로($i,\; f,\; g,\; o$)가 독립적으로 가지는 학습 파라미터 |
| **$\Delta c$** | **셀 상태 변화량** | 망각 게이트 비율($f$)이 변했을 때 달라지는 장기 기억의 차이값 |

#### 📍[공식] LSTM 순전파 공식과 쓰이는 이유

- **망각 게이트**
  $$f = \sigma(a_f) = \sigma(W_{xf}x_t + W_{hf}h_{t-1} + b_f)$$
  - **쓰이는 이유**: 과거 장기 기억($c_{t-1}$) 중에서 필요 없는 정보는 지우고(`0`에 가깝게), 유지할 정보만 남기기(`1`에 가깝게) 위해 비율을 계산한다.

- **입력 게이트 및 새 기억 후보**
  $$i = \sigma(a_i) = \sigma(W_{xi}x_t + W_{hi}h_{t-1} + b_i), \qquad g = \tanh(a_g) = \tanh(W_{xg}x_t + W_{hg}h_{t-1} + b_g)$$
  - **쓰이는 이유**: 현재 입력으로부터 장기 기억에 새로 기록할 후보 내용($g$)을 만들고, 그중 얼마나 반영할지 비율($i$)을 정하기 위해 사용한다.

- **셀 상태 업데이트**
  $$c_t = \underbrace{(f \odot c_{t-1})}_{\text{보존분}} + \underbrace{(i \odot g)}_{\text{새 기억 추가분}}$$
  - **쓰이는 이유**: 가중치 행렬 곱 없이 원소곱($\odot$)과 덧셈($+$)만으로 장기 기억을 갱신한다. 셀 상태를 직접 지나는 경로에는 $f$만 곱해지므로, $f$가 1에 가까우면 기울기가 거의 줄지 않고 과거까지 전달된다.

- **망각 게이트 변화에 따른 셀 상태 변화량**
  $$\Delta c = (f_{\text{새}} - f_{\text{기준}}) \odot c_{t-1}$$
  - **쓰이는 이유**: 다른 조건($i, g$)이 같을 때 $f$를 조절하면 장기 기억($c_t$)이 실제로 얼마나 변하는지($\Delta c = c_{\text{새}} - c_{\text{기준}}$) 확인하기 위해 사용한다.

- **출력 게이트 및 은닉 상태 출력**
  $$o = \sigma(a_o) = \sigma(W_{xo}x_t + W_{ho}h_{t-1} + b_o), \qquad h_t = o \odot \tanh(c_t)$$
  - **쓰이는 이유**: 장기 기억 전체($c_t$)를 그대로 노출하지 않고 $\tanh$로 다듬은 뒤, 현재 예측에 필요한 부분만 출력 비율($o$)만큼 걸러 단기 기억($h_t$)으로 내보내기 위해 사용한다.

### 2. LSTM 극단 상황 검증

📍[예시] 게이트 값이 0일 때의 동작 (세 가지는 서로 독립된 조건)

- **1단계: 과거 기억 완전 삭제 ($f=0$)**
  $$f = 0 \implies f \odot c_{t-1} = 0 \implies c_t = i \odot g$$
  - 이전 셀 상태($c_{t-1}$)가 모두 지워지고 새로 들어온 기억($i \odot g$)만 남는다.

- **2단계: 장기 기억이 비어 있을 때 ($c_t=0$)**
  $$c_t = 0 \implies h_t = o \odot \tanh(0) = 0$$
  - $\tanh(0)=0$이므로 출력 게이트($o$) 값과 상관없이 $h_t$도 `0`이 된다. ($f=0$만으로는 $c_t=0$이 되지 않고, $i \odot g$도 0이어야 한다.)

- **3단계: 출력 게이트 닫힘 ($o=0$)**
  $$o = 0 \implies h_t = 0, \quad c_t \text{는 그대로}$$
  - 출력 게이트는 밖으로 내보내는 양만 조절하고 셀 상태는 바꾸지 않는다.

### 3. GRU 기호 및 공식

#### 🔍[기호] GRU 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | GRU가 쓰는 **유일한 상태** (셀 상태 $c$ 없음) |
| **$r$** | **리셋 게이트 (Reset gate)** | 후보를 만들 때 이전 상태의 기여를 조절하는 비율 ($0 \sim 1$) |
| **$z$** | **업데이트 게이트 (Update gate)** | 새 상태에서 이전 상태를 남길 비율 ($0 \sim 1$) |
| **$n$** | **후보 상태 (New)** | 이번에 새로 만든 후보 ($-1 \sim +1$) |
| **$1-z$** | **후보 반영 비율** | 남기고 남은 만큼 후보를 받아들이는 비율 |
| **$W_{xq},\; W_{hq}$** | **입력/상태 가중치** | $q$는 $r,\; z,\; n$ 중 하나 ($x$는 입력, $h$는 이전 은닉 상태에서 오는 경로) |

#### 📍[공식] GRU 공식과 쓰이는 이유 (파이토치 정의)

- **리셋 게이트와 업데이트 게이트**
  $$r = \sigma(W_{xr}x_t + W_{hr}h_{t-1} + b_r), \qquad z = \sigma(W_{xz}x_t + W_{hz}h_{t-1} + b_z)$$
  - **쓰이는 이유**: $r$은 이전 상태를 후보에 얼마나 섞을지, $z$는 이전 상태를 최종적으로 얼마나 남길지 비율로 정하기 위해 사용한다. (파이토치는 $r,\; z$의 편향도 입력 쪽, 상태 쪽 둘로 나눠 저장하며 합치면 위 식의 $b_r,\; b_z$와 같다.)

- **후보 상태**
  $$n = \tanh\big(W_{xn}x_t + b_{xn} + r \odot (W_{hn}h_{t-1} + b_{hn})\big)$$
  - **쓰이는 이유**: 입력과 (리셋 게이트로 줄인) 이전 상태를 합쳐 이번에 새로 쓸 내용을 만들기 위해 사용한다. $r$은 **상태 쪽 항에만** 곱해진다.

- **새 은닉 상태**
  $$h_t = (1-z) \odot n + z \odot h_{t-1}$$
  - **쓰이는 이유**: 이전 상태와 후보를 $z$ 비율로 섞어 새 상태를 만든다. LSTM의 망각 게이트와 입력 게이트가 $z$와 $(1-z)$ 한 쌍으로 합쳐진 형태다.

📍[예시] $h_{t-1}=0.5,\ n=-0.3$일 때 $z$의 효과

| $z$ | 계산 | 새 은닉 상태 $h_t$ |
|:---:|:---:|:---:|
| **1** | $1\times0.5+0\times(-0.3)$ | **0.5** (이전 상태 그대로) |
| **0.7** | $0.7\times0.5+0.3\times(-0.3)$ | **0.26** |
| **0.2** | $0.2\times0.5+0.8\times(-0.3)$ | **−0.14** |
| **0** | $0\times0.5+1\times(-0.3)$ | **−0.3** (후보로 완전히 덮어씀) |

- $r=0$이면 상태 쪽 항이 사라져 후보는 $\tanh(W_{xn}x_t + b_{xn})$, 즉 입력만으로 정해진다.
- $z=1$이면 $h_t=h_{t-1}$이라 기울기가 줄지 않고 흐르는 경로가 된다.
- 상태가 여러 칸이면 칸마다 $z$가 따로 있어, 칸별로 남길지 바꿀지를 정한다.

### 4. LSTM과 GRU 비교

| 구분 | LSTM | GRU |
|:---:|:---:|:---:|
| **상태** | 셀 상태 $c$, 은닉 상태 $h$ | 은닉 상태 $h$ |
| **게이트** | 입력 $i$, 망각 $f$, 출력 $o$ + 후보 $g$ | 리셋 $r$, 업데이트 $z$ + 후보 $n$ |
| **새 상태** | $c$를 갱신한 뒤 $h$를 꺼냄 | 후보를 이전 $h$와 섞음 |
| **반환값** | `output, (h_n, c_n)` | `output, h_n` |
