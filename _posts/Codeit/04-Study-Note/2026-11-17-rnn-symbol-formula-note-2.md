### 1. 학습 한 번의 순서

| 순서 | 단계 | 하는 일 |
|:---:|:---:|:---|
| **1** | **순전파 (forward)** | 입력을 넣어 예측값 $\hat{y}$ 계산 (1편 2절) |
| **2** | **손실 계산** | 예측값과 정답의 오차 $L$ 계산 |
| **3** | **역전파 (backward)** | 기울기(가중치 변화에 따른 손실 변화율) 계산 (가중치는 미변경) |
| **4** | **`optimizer.step`** | 계산된 기울기로 가중치 실제 업데이트 |

### 2. 역전파(BPTT) 기호 및 공식

- **BPTT**: 시간을 거슬러 올라가며 기울기를 계산하는 역전파 (3번 단계)

#### 🔍[기호] 역전파 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$\delta_t$** | **오차 신호** | 시점 $t$의 가중합($a_t$) 변화에 따른 손실($L$) 변화율 ($\partial L / \partial a_t$) |
| **$1-h_t^2$** | **tanh 미분값** | $\tanh$ 통과 시 기울기 축소 비율 ($h_t$가 $\pm 1$에 가까울수록 0에 근접) |
| **$W^T$** | **전치 행렬** | 행과 열을 바꾼 행렬 (기울기 역전달 시 사용) |
| **$\odot$** | **원소곱** | 같은 칸끼리 1:1로 곱하는 연산 |
| **$\partial L / \partial W_{hh}$** | **순환 가중치 기울기** | $W_{hh}$ 변화에 따른 손실($L$) 변화율 |

#### 📍[공식] 역전파 (BPTT) 공식

- **마지막 시점의 오차 신호** (출력층 없을 시 $\delta_T = (\hat{y}_T - y_T)\odot(1-h_T^2)$)
  $$\delta_T = \big(W_{hy}^{T}(\hat{y}_T - y_T)\big) \odot (1 - h_T^2)$$
- **이전 시점으로 오차 신호 전달** (마지막 시점에만 손실 존재 시)
  $$\delta_{t-1} = (W_{hh}^{T}\delta_t) \odot (1 - h_{t-1}^2)$$
- **공유 가중치의 최종 기울기 합산** (직렬 경로는 곱하고, 공유 가중치의 시점별 기여는 합산)
  $$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \delta_t\, h_{t-1}^T, \qquad \frac{\partial L}{\partial W_{xh}} = \sum_{t=1}^{T} \delta_t\, x_t^T, \qquad \frac{\partial L}{\partial b_h} = \sum_{t=1}^{T} \delta_t$$

### 3. 기울기 소실·폭발과 클리핑

#### 🔍[비교] 소실과 폭발

| 구분 | 조건 | 결과 | 대응 |
|:---:|:---:|:---|:---:|
| **기울기 소실** | 시점마다 곱해지는 인자 크기 $< 1$ | 먼 과거로 갈수록 기울기가 0에 수렴해 초기 시점 학습 불가 | LSTM (4절), GRU (3편) |
| **기울기 폭발** | 시점마다 곱해지는 인자 크기 $> 1$ | 기울기가 폭증하여 학습 불안정 및 `NaN` 발생 | 기울기 클리핑 |

📍[예시] 인자($W_{hh}(1-h^2)$)를 10번 반복 곱셈 시 ($T=10$)

- 인자 0.5: $0.5^{10} \approx 0.00098$ (소실) / 인자 1.5: $1.5^{10} \approx 57.7$ (폭발)

- **기울기 클리핑**: 기울기가 임계값을 초과할 때 상한선으로 잘라내는 기법 (폭발만 방지하며 소실은 해결 불가)
- ⚠️ **장기 의존**(먼 과거 문맥이 필요한 문제 특성)과 **기울기 소실**(역전파 신호 소멸 현상)은 별개 개념

### 4. LSTM(장단기 메모리) 기호 및 공식

#### 🔍[기호] LSTM 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$x_t$** | **현재 입력** | 이번 시점($t$)에 들어온 값 |
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | 직전 시점의 단기 기억 및 이번 시점의 최종 출력 |
| **$c_{t-1},\; c_t$** | **이전 / 현재 셀 상태** | 직전 시점까지 보존된 장기 기억 및 갱신된 장기 기억 |
| **$f$** | **망각 게이트 (Forget gate)** | 이전 셀 상태($c_{t-1}$)에서 남길 비율 ($0 \sim 1$) |
| **$i$** | **입력 게이트 (Input gate)** | 새 기억 후보($g$)를 장기 기억에 반영할 비율 ($0 \sim 1$) |
| **$g$** | **새 기억 후보 (Candidate)** | 이번에 새로 저장할 후보 내용 ($-1 \sim +1$) |
| **$o$** | **출력 게이트 (Output gate)** | 셀 상태($c_t$)를 은닉 출력($h_t$)에 반영할 비율 ($0 \sim 1$) |
| **$a_q$** | **가중합** | 활성화 함수 적용 전 선형 결합 값 ($q \in \{i,\; f,\; g,\; o\}$) |
| **$\sigma$** | **시그모이드 (Sigmoid)** | 값을 $0 \sim 1$ 사이로 눌러 게이트 비율을 만드는 함수 |
| **$W_x,\; W_h,\; b$** | **입력/상태 가중치, 편향** | 각 경로($i,\; f,\; g,\; o$)별 독립 학습 파라미터 |
| **$\Delta c$** | **셀 상태 변화량** | 망각 게이트 비율($f$) 변화에 따른 장기 기억 차이값 |

#### 📍[공식] LSTM 순전파 공식

- **망각 게이트**
  $$f = \sigma(a_f) = \sigma(W_{xf}x_t + W_{hf}h_{t-1} + b_f)$$
- **입력 게이트 및 새 기억 후보**
  $$i = \sigma(a_i) = \sigma(W_{xi}x_t + W_{hi}h_{t-1} + b_i), \qquad g = \tanh(a_g) = \tanh(W_{xg}x_t + W_{hg}h_{t-1} + b_g)$$
- **셀 상태 업데이트** ($f \approx 1$이면 가중치 곱 없이 기울기가 과거까지 직통 전달)
  $$c_t = \underbrace{(f \odot c_{t-1})}_{\text{보존분}} + \underbrace{(i \odot g)}_{\text{새 기억 추가분}}$$
- **망각 게이트 변화에 따른 셀 상태 변화량**
  $$\Delta c = (f_{\text{새}} - f_{\text{기준}}) \odot c_{t-1}$$
- **출력 게이트 및 은닉 상태 출력**
  $$o = \sigma(a_o) = \sigma(W_{xo}x_t + W_{ho}h_{t-1} + b_o), \qquad h_t = o \odot \tanh(c_t)$$

### 5. LSTM 극단 상황 검증

📍[예시] 게이트 값이 0일 때의 독립적 동작

- **1단계: 과거 기억 완전 삭제 ($f=0$)**
  $$f = 0 \implies f \odot c_{t-1} = 0 \implies c_t = i \odot g$$
- **2단계: 장기 기억이 비어 있을 때 ($c_t=0$)** ($f=0$과 $i \odot g = 0$이 동시에 성립할 때)
  $$c_t = 0 \implies h_t = o \odot \tanh(0) = 0$$
- **3단계: 출력 게이트 닫힘 ($o=0$)** (셀 상태 $c_t$는 변하지 않음)
  $$o = 0 \implies h_t = 0, \quad c_t \text{는 그대로}$$
