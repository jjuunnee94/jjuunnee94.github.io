## 1. ResNet 이후의 모델

| 모델 | 연도 | 핵심 아이디어 |
|:---:|:---:|:---:|:---:|
| ResNeXt | 2016~2017 | 잔차 구조에 카디널리티(cardinality)라는 새로운 차원을 추가, 2016년 대회 분류 부문 2위 |
| DenseNet | 2016~2017 | 모든 층을 서로 연결(n개 층이면 n(n+1)/2개 연결), 앞선 특징 재사용 |
| SENet | 2017 | SE 블록으로 채널별 반응을 재조정, 2017년 대회 우승(2.251%) |
| MobileNet | 2017 | 합성곱을 두 단계로 쪼갠 깊이별 분리 합성곱(depthwise separable convolution)으로 계산량 축소 |
| EfficientNet | 2019 | 깊이·너비·해상도를 한꺼번에 비율로 키우는 복합 스케일링(compound scaling) |
| ViT | 2020~2021 | 이미지를 패치로 잘라 트랜스포머에 입력, 합성곱을 쓰지 않음 |

## 2. 효율을 높이는 세 방향

| 모델 | 방향 | 설명 |
|:---:|:---:|:---:|
| DenseNet | 특징 재사용 | 중복된 특징을 다시 학습하지 않아 파라미터 효율과 기울기 흐름 개선, 대신 메모리 사용량이 큼 |
| MobileNet | 계산량 감소 | 합성곱 연산 자체를 바꿔 자원이 제한된 환경(모바일)에 적합 |
| EfficientNet | 체계적 크기 조절 | 신경망 구조 탐색(NAS)으로 기본 모델을 만들고 복합 스케일링으로 키움 |

- EfficientNet 논문 기준: EfficientNet-B4는 ResNet-50과 FLOPs가 비슷한데 top-1 정확도가 76.3%에서 83.0%로 상승
- 같은 논문에서 2017년 우승 모델 SENet은 82.7% top-1 정확도에 파라미터가 1억 4500만 개
- 2017년 SENet은 정확도를 위해 모델이 커진 사례이고, 이후 모델은 같은 정확도를 더 적은 계산량으로 내는 방향으로 이동

## 3. 합성곱을 쓰지 않는 ViT

- 이미지를 16×16 패치로 자르고, 각 패치를 문장 속 단어처럼 취급해 표준 트랜스포머에 입력
- 합성곱과 사람이 설계한 특징 없이 패치와 어텐션만 사용
- 매우 큰 데이터셋(JFT-300M)으로 학습했을 때 CNN 수준의 정확도를 달성
- 이후 DeiT, Swin Transformer처럼 개선된 비전 트랜스포머가 이어짐
