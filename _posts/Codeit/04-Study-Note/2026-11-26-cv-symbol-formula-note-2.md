#### 🔍[기호] 필터·경계·주파수 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---:|
| **I** | **입력 이미지** | 원본 픽셀 값 |
| **K** | **필터(커널)** | 모든 위치에 같게 곱하는 가중치 묶음 |
| **O** | **출력 이미지** | 필터를 적용한 결과 |
| **B** | **블러 결과** | 흐리게 만든 이미지 |
| **σ** | **가우시안 표준편차** | 클수록 넓게 평균해 더 흐려짐 |
| **Gx** | **가로 기울기** | 가로 방향 밝기 변화 |
| **Gy** | **세로 기울기** | 세로 방향 밝기 변화 |
| **G** | **기울기 크기** | 경계의 세기 |
| **P** | **무늬 주기** | 밝기 무늬가 반복되는 간격 |
| **d** | **표본 간격** | 픽셀을 뽑는 간격 |

#### 📍[공식] 필터링 · 합성곱

- **필터링(교차상관)** (3칸 필터)
  - 출력 O = 이웃 픽셀 × 같은 위치 필터 값의 합

$$O_i = \sum_{u=-1}^{1} K_u \, I_{i+u}$$

- **합성곱**
  - 필터를 **뒤집어서** 같은 계산, 좌우 대칭 필터면 교차상관과 같음

$$O_i = \sum_{u=-1}^{1} K_{-u} \, I_{i+u}$$

- **가우시안 가중치**
  - 가중치 K = 가운데에서 멀수록 작아지는 종 모양

$$K_u \propto e^{-u^2 / (2\sigma^2)}$$

#### 📍[공식] 샤프닝 · 경계 · 에일리어싱

- **샤프닝**
  - 샤프닝 결과 = 원본 I + (원본 I − 블러 B)

$$I_{\text{sharp}} = I + (I - B)$$

- **Sobel 기울기 크기**
  - 기울기 크기 G = √(가로 기울기 Gx² + 세로 기울기 Gy²)

$$G = \sqrt{G_x^{2} + G_y^{2}}$$

- **에일리어싱 조건**
  - 무늬 주기 P가 표본 간격 d의 2배보다 짧으면 가짜 느린 무늬

$$P < 2d$$

#### 🔍[비교] Canny 4단계

| 순서 | 단계 | 하는 일 |
|:---:|:---:|:---:|
| 1 | 평활 | 가우시안으로 잡음 제거 |
| 2 | 기울기 | Sobel로 Gx, Gy, G 계산 |
| 3 | 얇게 | 기울기가 가장 큰 곳만 남김 |
| 4 | 연결 | 낮은 임계값과 높은 임계값으로 경계 연결 |
