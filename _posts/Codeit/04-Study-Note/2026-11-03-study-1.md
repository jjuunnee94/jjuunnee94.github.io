### 1. 헷갈리는 zero들

```python
with torch.no_grad():           # 계산을 기록하지 않는다.
    model.layer.weight.zero_()  # weight 값을 0으로 만든다.
    model.layer.bias.zero_()    # bias 값을 0으로 만든다.
optimizer.zero_grad()           # 기존 기울기값을 0으로 만든다.
```

### 2. nn.Linear 특징

- `nn.Linear`는 만들 때 `weight`와 `bias`를 **랜덤 초기값**으로 채운다.
- `nn.Linear`는 첫번째 층은 0이되면 안되고 그 이후 층은 0이 되어도 된다.
- `ReLU` 없이 `Linear`를 두 개 이어 붙이면 결국 직선 하나와 같아서, 좌우 기울기가 다른 모양을 만들 수 없다.

### 3. 코드 순서 및 특징

```python
import torch
from torch import nn

model = nn.Linear(1, 1) # 모델에 변수 할당

with torch.no_grad():
    model.weight.zero_()
    model.bias.zero_()

# 반드시 실제 사용할 model의 parameters()를 넘겨야 step() 호출 시 해당 모델이 갱신됨
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

# 데이터 준비
x = torch.tensor([[1.], [2.]])
y = torch.tensor([[3.], [5.]])

# 이전 스텝 기울기 비우기 및 순전파/역전파 실행
optimizer.zero_grad()
loss = (model(x) - y).square().mean()  # 갱신 전 손실(loss) 계산: 17.0
loss.backward()                         # 역전파로 .grad 계산: w의 grad = -13.0

weight_before = model.weight.detach().clone()  # 갱신 전 계수 보관: 0.0 (나중에 비교를 위해)
grad_weight = model.weight.grad.detach().clone() # 기울기 보관: -13.0 (.grad는 step()으로 지워지지 않음)

optimizer.step()  # w = 0 - 0.1 * (-13.0) = 1.3 으로 파라미터 갱신

with torch.no_grad():  # 갱신 후 평가: step() 이후에는 no_grad() 안에서 loss를 다시 계산해야 갱신 후 손실을 얻을 수 있음
    weight_after = model.weight.detach().clone()  # 갱신 후 계수: 1.3
    loss_after = (model(x) - y).square().mean()   # 갱신 후 손실: 1.685 (loss 변수는 자동으로 안 바뀜)


print(loss.item(), weight_before.item(), grad_weight.item())  # 17.0 0.0 -13.0
print(weight_after.item(), loss_after.item())                  # 1.3 1.685
# 출력 및 변환: .item()은 단일 요소 Tensor를 파이썬 숫자로 변환함 (여러 값은 .tolist() 사용)
```

### 4. Dataset과 DataLoader

```python
import torch
from torch.utils.data import Dataset, DataLoader

# [4. Dataset 정의] Custom Dataset 클래스 (__len__은 표본 수, __getitem__은 개별 (x, y) 반환)
class PairData(Dataset):
    def __init__(self, x, y):
        self.x = x
        self.y = y
    def __len__(self):
        return len(self.x)  # 표본 수(7) 반환 (DataLoader의 배치 수와 다름)
    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]  # idx번째 표본 (x, y) 쌍 반환 (ds[2]는 세 번째 표본)

# 데이터셋 및 DataLoader 생성
x = torch.tensor([[1.], [2.], [3.], [4.], [5.], [6.], [7.]])  
y = 2 * x + 1                                                 
ds = PairData(x, y)  # Dataset 객체 생성 (len(ds) == 7)
loader = DataLoader(ds, batch_size=3, shuffle=False, drop_last=False)
# batch_size=3 : 3개씩 묶음 -> 배치 구성: 3, 3, 1개 (마지막 배치는 더 작음)
# shuffle=False : 데이터를 섞자 않음 
# drop_last=False) : 마지막 남은 데이터를 버리지 않고 사용

# 확인용 출력
print(len(ds), ds[2])   # 출력: 7 (tensor([3.]), tensor([7.])) -> 표본 수 및 3번째 표본
print([(tuple(xb.shape), tuple(yb.shape)) for xb, yb in loader])
# 출력: [((3, 1), (3, 1)), ((3, 1), (3, 1)), ((1, 1), (1, 1))]
```

### 5. 표준학습루프

```python
for xb, yb in loader:
    optimizer.zero_grad()                 
    pred = model(xb)                      # 예측값 계산
    loss = (pred - yb).square().mean()    # 손실
    loss.backward()                       # 역전파
    optimizer.step()                      # 파라미터 갱신 
```

### 6. device

### 7. logits, CrossEntropyLoss

- `logits`의 한 행은 표본, 한 열은 class이다.
- **정답 점수**는 모델이 **정답 class에 준 점수**이다. 정답 label이 `0`이면 그 행의 `0`번 열 값이다.
- 정답 점수가 다른 class보다 높을수록 정답 확률이 높아지고, 손실은 작아진다.
- 정답 `labels`는 `(N,)`, `long`(64비트 정수)이어야 한다. `(N, 1)`로 만들면 `CrossEntropyLoss`가 받는 형태가 아니다.
- `logits`는 softmax 전 점수를 **그대로** 넣는다. 확률로 바꾼 값을 넣으면 softmax가 두 번 적용된다.
