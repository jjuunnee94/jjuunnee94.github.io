### 1. GRU 기호 및 공식

#### 🔍[기호] GRU 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | GRU가 쓰는 **유일한 상태** (셀 상태 $c$ 없음) |
| **$r$** | **리셋 게이트 (Reset gate)** | 후보 생성 시 이전 상태의 기여 비율 ($0 \sim 1$) |
| **$z$** | **업데이트 게이트 (Update gate)** | 새 상태에서 이전 상태를 남길 비율 ($0 \sim 1$) |
| **$n$** | **후보 상태 (New)** | 이번에 새로 만든 후보 ($-1 \sim +1$) |
| **$1-z$** | **후보 반영 비율** | 남기고 남은 만큼 후보를 받아들이는 비율 |
| **$W_{xq},\; W_{hq}$** | **입력 / 상태 가중치** | $q \in \{r,\; z,\; n\}$ ($x$: 입력, $h$: 이전 상태 경로) |

#### 📍[공식] GRU 공식 (파이토치 정의)

- **리셋 게이트와 업데이트 게이트**
  $$r = \sigma(W_{xr}x_t + W_{hr}h_{t-1} + b_r), \qquad z = \sigma(W_{xz}x_t + W_{hz}h_{t-1} + b_z)$$
- **후보 상태** ($r$은 상태 쪽 항에만 곱함)
  $$n = \tanh\big(W_{xn}x_t + b_{xn} + r \odot (W_{hn}h_{t-1} + b_{hn})\big)$$
- **새 은닉 상태** ($z$와 $1-z$ 비율로 혼합)
  $$h_t = (1-z) \odot n + z \odot h_{t-1}$$

### 2. LSTM과 GRU 비교

| 구분 | LSTM | GRU |
|:---:|:---:|:---:|
| **상태** | 셀 상태 $c$, 은닉 상태 $h$ | 은닉 상태 $h$ |
| **게이트** | 입력 $i$, 망각 $f$, 출력 $o$ + 후보 $g$ | 리셋 $r$, 업데이트 $z$ + 후보 $n$ |
| **새 상태** | $c$를 갱신한 뒤 $h$를 꺼냄 | 후보를 이전 $h$와 섞음 |

---

### 3. LSTM · GRU 입출력 모양 규칙

#### 📍[규칙] 입출력 모양 ($B$: 예제 수, $T$: 시점 수, $F$: 입력 칸 수, $H$: 상태 칸 수, $K$: 층 수, $D$: 방향 수)

| 모듈 | 입력 | 반환값과 모양 |
|:---:|:---:|:---|
| **`nn.LSTM`** | ($B$, $T$, $F$) | `output` ($B$, $T$, $D \cdot H$), `h_n`, `c_n` 각각 ($K \cdot D$, $B$, $H$) |
| **`nn.GRU`** | ($B$, $T$, $F$) | `output` ($B$, $T$, $D \cdot H$), `h_n` ($K \cdot D$, $B$, $H$) (`c_n` 없음) |
| **`nn.LSTMCell`** (한 시점) | $x$: ($B$, $F$), `(h, c)`: 각각 ($B$, $H$) | `(h, c)`: 각각 ($B$, $H$) |

- 호출: `output, (h_n, c_n) = lstm(x)` / `output, h_n = gru(x)`
- `c_n`: 마지막 시점의 셀 상태 (`output`에는 은닉 상태만 포함되므로 별도 반환)

### 4. 파라미터 수와 가중치 모양

#### 🔍[기호] 파이토치 가중치 이름

| 이름 | 뜻 |
|:---:|:---|
| **`weight_ih_l0`** | 첫 층의 입력 → 상태 가중치 ($W_{xh}$) |
| **`weight_hh_l0`** | 첫 층의 상태 → 상태 가중치 ($W_{hh}$) |
| **`bias_ih_l0`, `bias_hh_l0`** | 입력 쪽, 상태 쪽 편향 (두 벌) |

#### 🔍[비교] 가중치 모양 ($F$: 입력 칸 수, $H$: 상태 칸 수)

| 모델 | 게이트 묶음 순서 | `weight_ih_l0` | `weight_hh_l0` | 편향 각각 | 파라미터 수 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **RNN** | 없음 (1묶음) | ($H$, $F$) | ($H$, $H$) | ($H$,) | $HF+H^2+2H$ |
| **GRU** | $r,\; z,\; n$ (3묶음) | ($3H$, $F$) | ($3H$, $H$) | ($3H$,) | $3(HF+H^2+2H)$ |
| **LSTM** | $i,\; f,\; g,\; o$ (4묶음) | ($4H$, $F$) | ($4H$, $H$) | ($4H$,) | $4(HF+H^2+2H)$ |

- 편향이 입력·상태 양쪽에 존재하여 각각 $+2H$ 반영
- 2층 이상일 경우 둘째 층부터 입력 칸 수 $F$ 자리에 $D \cdot H$ 적용

### 5. 양방향 RNN

- 인자: `bidirectional=True` ($D=2$)

#### 📍[공식] 양방향 RNN 순전파

- **정방향(Forward) 및 역방향(Backward) 은닉 상태**
  $$\overrightarrow{h}_t = \text{RNN}_{\text{fwd}}(x_t, \overrightarrow{h}_{t-1}), \qquad \overleftarrow{h}_t = \text{RNN}_{\text{bwd}}(x_t, \overleftarrow{h}_{t+1})$$
- **최종 출력 결합**
  $$h_t = \big[\,\overrightarrow{h}_t \; ; \; \overleftarrow{h}_t\,\big]$$

#### 🔍[비교] 양방향의 모양 규칙 ($B$: 예제 수, $T$: 시점 수, $H$: 상태 칸 수)

| 값 | 모양 | 뜻 |
|:---:|:---:|:---|
| **`output`** | ($B$, $T$, $2H$) | 앞 $H$칸은 정방향, 뒤 $H$칸은 역방향 |
| **`h_n`, `c_n`** | (2, $B$, $H$) | `[0]` 정방향의 마지막, `[1]` 역방향의 마지막 |

- 한 층 기준 슬라이싱 관계: `h_n[0] = output[:, -1, :H]`, `h_n[1] = output[:, 0, H:]`
- 파라미터 수: 역방향 가중치(`_reverse`) 추가로 **단방향의 2배**
