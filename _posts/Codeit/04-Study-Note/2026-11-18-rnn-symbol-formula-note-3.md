### 1. GRU 기호 및 공식

#### 🔍[기호] GRU 기호 · 이름 · 뜻

| 기호 | 이름 | 뜻 |
|:---:|:---:|:---|
| **$h_{t-1},\; h_t$** | **이전 / 현재 은닉 상태** | GRU가 쓰는 **유일한 상태** (셀 상태 $c$ 없음) |
| **$r$** | **리셋 게이트 (Reset gate)** | 후보를 만들 때 이전 상태의 기여를 조절하는 비율 ($0 \sim 1$) |
| **$z$** | **업데이트 게이트 (Update gate)** | 새 상태에서 이전 상태를 남길 비율 ($0 \sim 1$) |
| **$n$** | **후보 상태 (New)** | 이번에 새로 만든 후보 ($-1 \sim +1$) |
| **$1-z$** | **후보 반영 비율** | 남기고 남은 만큼 후보를 받아들이는 비율 |
| **$W_{xq},\; W_{hq}$** | **입력/상태 가중치** | $q$는 $r,\; z,\; n$ 중 하나 ($x$는 입력, $h$는 이전 은닉 상태에서 오는 경로) |

#### 📍[공식] GRU 공식과 쓰이는 이유 (파이토치 정의)

- **리셋 게이트와 업데이트 게이트**
  $$r = \sigma(W_{xr}x_t + W_{hr}h_{t-1} + b_r), \qquad z = \sigma(W_{xz}x_t + W_{hz}h_{t-1} + b_z)$$
  - **쓰이는 이유**: $r$은 이전 상태를 후보에 얼마나 섞을지, $z$는 이전 상태를 최종적으로 얼마나 남길지 비율로 정하기 위해 사용한다. (파이토치는 $r,\; z$의 편향도 입력 쪽, 상태 쪽 둘로 나눠 저장하며 합치면 위 식의 $b_r,\; b_z$와 같다.)

- **후보 상태**
  $$n = \tanh\big(W_{xn}x_t + b_{xn} + r \odot (W_{hn}h_{t-1} + b_{hn})\big)$$
  - **쓰이는 이유**: 입력과 (리셋 게이트로 줄인) 이전 상태를 합쳐 이번에 새로 쓸 내용을 만들기 위해 사용한다. $r$은 **상태 쪽 항에만** 곱해진다.

- **새 은닉 상태**
  $$h_t = (1-z) \odot n + z \odot h_{t-1}$$
  - **쓰이는 이유**: 이전 상태와 후보를 $z$ 비율로 섞어 새 상태를 만든다. LSTM의 망각 게이트($f$)와 입력 게이트($i$)가 $z$와 $(1-z)$ 한 쌍으로 합쳐진 형태다.

📍[예시] $h_{t-1}=0.5,\ n=-0.3$일 때 $z$의 효과

| $z$ | 계산 | 새 은닉 상태 $h_t$ |
|:---:|:---:|:---:|
| **1** | $1\times0.5+0\times(-0.3)$ | **0.5** (이전 상태 그대로) |
| **0.7** | $0.7\times0.5+0.3\times(-0.3)$ | **0.26** |
| **0.2** | $0.2\times0.5+0.8\times(-0.3)$ | **−0.14** |
| **0** | $0\times0.5+1\times(-0.3)$ | **−0.3** (후보로 완전히 덮어씀) |

- $r=0$이면 상태 쪽 항이 사라져 후보는 $\tanh(W_{xn}x_t + b_{xn})$, 즉 입력만으로 정해진다.
- $z=1$이면 $h_t=h_{t-1}$이라 기울기가 줄지 않고 흐르는 경로가 된다.
- 상태가 여러 칸이면 칸마다 $z$가 따로 있어, 칸별로 남길지 바꿀지를 정한다.

### 2. LSTM과 GRU 비교

| 구분 | LSTM | GRU |
|:---:|:---:|:---:|
| **상태** | 셀 상태 $c$, 은닉 상태 $h$ | 은닉 상태 $h$ |
| **게이트** | 입력 $i$, 망각 $f$, 출력 $o$ + 후보 $g$ | 리셋 $r$, 업데이트 $z$ + 후보 $n$ |
| **새 상태** | $c$를 갱신한 뒤 $h$를 꺼냄 | 후보를 이전 $h$와 섞음 |

### 3. LSTM · GRU 입출력 모양 규칙

#### 📍[규칙] 입출력 모양 ($B$: 예제 수, $T$: 시점 수, $F$: 입력 칸 수, $H$: 상태 칸 수, $K$: 층 수, $D$: 방향 수)

- `c_n`: 마지막 시점의 셀 상태 (`output`에는 은닉 상태만 들어 있어서 따로 반환되고, `h_n`과 다른 값일 수 있음)

| 모듈 | 입력 | 반환값과 모양 |
|:---:|:---:|:---|
| **`nn.LSTM`** | ($B$, $T$, $F$) | `output` ($B$, $T$, $D \cdot H$), `h_n`, `c_n` 각각 ($K \cdot D$, $B$, $H$) |
| **`nn.GRU`** | ($B$, $T$, $F$) | `output` ($B$, $T$, $D \cdot H$), `h_n` ($K \cdot D$, $B$, $H$) (`c_n` 없음) |
| **`nn.LSTMCell`** (한 시점) | $x$: ($B$, $F$), `(h, c)`: 각각 ($B$, $H$) | `(h, c)`: 각각 ($B$, $H$) |

- 호출 형태: `output, (h_n, c_n) = lstm(x)`, `output, h_n = gru(x)` (반환 괄호는 상태 수를 반영)
- `output`과 `h_n`의 관계, 초기 상태, 입력 길이에 따른 변화는 1편 3절과 같음

### 4. 파라미터 수와 가중치 모양

#### 🔍[기호] 파이토치 가중치 이름

| 이름 | 뜻 |
|:---:|:---|
| **`weight_ih_l0`** | 첫 층의 입력 → 상태 가중치 (1편의 $W_{xh}$에 해당) |
| **`weight_hh_l0`** | 첫 층의 상태 → 상태 가중치 (1편의 $W_{hh}$에 해당) |
| **`bias_ih_l0`, `bias_hh_l0`** | 입력 쪽, 상태 쪽 편향 (두 벌) |

#### 🔍[비교] 가중치 모양 ($F$: 입력 칸 수, $H$: 상태 칸 수)

| 모델 | 게이트 묶음 쌓는 순서 | `weight_ih_l0` | `weight_hh_l0` | 편향 각각 | 파라미터 수 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **RNN** | 없음 (1묶음) | ($H$, $F$) | ($H$, $H$) | ($H$,) | $HF+H^2+2H$ |
| **GRU** | $r,\; z,\; n$ (3묶음) | ($3H$, $F$) | ($3H$, $H$) | ($3H$,) | $3(HF+H^2+2H)$ |
| **LSTM** | $i,\; f,\; g,\; o$ (4묶음) | ($4H$, $F$) | ($4H$, $H$) | ($4H$,) | $4(HF+H^2+2H)$ |

- 편향이 입력 쪽, 상태 쪽 두 벌이라 파라미터 수에 $2H$가 더해짐
- 게이트별 가중치를 세로로 쌓아 한 번의 행렬곱으로 계산하고, 결과를 `chunk`(텐서를 같은 크기로 나누는 함수)로 게이트별로 나눔
- ⚠️ 한 층 기준이다. 2층 이상이면 둘째 층부터 입력이 이전 층의 출력이므로 $F$ 자리에 $D \cdot H$가 들어간다.

📍[예시] $F=3$, $H=5$ (한 층, 단방향)

| 모델 | 계산 | 파라미터 수 |
|:---:|:---:|:---:|
| **RNN** | $5\times3+5^2+2\times5=15+25+10$ | **50** |
| **GRU** | $3\times50$ | **150** |
| **LSTM** | $4\times50$ | **200** |

### 5. 양방향 RNN

- 같은 입력창을 **앞→뒤**, **뒤→앞**으로 한 번씩 읽고, 위치별로 두 결과를 이어 붙임
- 정방향은 그 시점 이전을, 역방향은 그 시점 이후를 요약
- 인자: `bidirectional=True` ($D=2$)

#### 🔍[비교] 양방향의 모양 규칙 ($B$: 예제 수, $T$: 시점 수, $H$: 상태 칸 수)

| 값 | 모양 | 뜻 |
|:---:|:---:|:---|
| **`output`** | ($B$, $T$, $2H$) | 앞 $H$칸은 정방향, 뒤 $H$칸은 역방향 |
| **`h_n`, `c_n`** | (2, $B$, $H$) | `[0]` 정방향의 마지막, `[1]` 역방향의 마지막 |

- 역방향은 첫 위치를 **마지막에** 읽으므로 다음 관계가 성립 (한 층일 때)
  - `h_n[0]` = `output[:, -1, :H]`
  - `h_n[1]` = `output[:, 0, H:]`
- 정방향은 마지막 위치에서, 역방향은 첫 위치에서 입력 전체를 읽은 상태가 됨
- 역방향 값은 입력이 길어지면 달라지므로, "앞쪽 시점의 출력이 같다"는 성질은 단방향에만 해당
- 파라미터 수: 역방향 가중치(`_reverse`)가 한 벌 더 있어 **한 방향의 2배** (예: $F=3$, $H=5$ LSTM 200개 → 양방향 400개)
- ⚠️ 예측 시점에 아직 관측되지 않은 값(정답)은 입력창에 넣지 않는다.
