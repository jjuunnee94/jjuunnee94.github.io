## 1. 시각 피질 연구 (1959~1962)

| 연도 | 사건 | 내용 |
|:---:|:---:|:---:|
| 1959 | 허벨(Hubel)과 비즐(Wiesel)의 고양이 실험 | 마취한 고양이의 1차 시각 피질에 미세 전극을 꽂고 빛과 막대 이미지를 보여 주며 개별 뉴런의 반응을 관찰 |
| 1962 | 고양이 시각 피질 체계적 연구 | 뉴런 하나가 전체 시야가 아닌 특정 작은 영역만 처리한다는 수용장(receptive field) 개념 제시 |
| 1981 | 노벨 생리의학상 | 시각 정보 처리 메커니즘 규명 공로로 두 사람이 공동 수상자에 포함 |

- 단순 세포(simple cell): 특정 위치에 놓인 특정 방향의 막대·모서리 자극에 선택적으로 반응
- 복잡 세포(complex cell): 같은 방향을 선호하는 여러 단순 세포의 입력을 받아 위치 변화에 덜 민감하게 반응
- 시각 처리는 모서리 같은 단순한 저수준 특징에서 시작해 점점 복잡한 고수준 구조로 올라가는 계층 구조

## 2. 네오코그니트론 (1979~1980)

| 항목 | 내용 |
|:---:|:---:|
| 제안자 | 후쿠시마 쿠니히코(Kunihiko Fukushima) |
| 발표 | 1979년 일본어 논문, 1980년 학술지 Biological Cybernetics |
| 목표 | 입력 패턴의 위치가 옮겨져도 영향받지 않는 패턴 인식 |
| 구조 | 단순 세포형 층(S층)과 복잡 세포형 층(C층)을 번갈아 쌓음 |
| 학습 | 비지도 기반의 자기조직화(self-organization) 방식 |

- 합성곱층과 다운샘플링층(풀링층의 전신)이 처음 등장한 모델로 평가됨
- 이전 모델들(코그니트론 등)은 입력 패턴의 위치 이동과 모양 변형에 크게 흔들렸음
- 현대 CNN의 원형이지만, 오차 역전파(backpropagation)로 학습하는 구조는 아님

## 3. 역전파를 CNN에 적용 (1988~1998)

| 연도 | 사건 | 내용 |
|:---:|:---:|:---:|
| 1988 | 장웨이(Wei Zhang) 외 | 단순화한 네오코그니트론 구조에 역전파를 적용해 알파벳 문자 인식 구현 |
| 1989 | 얀 르쿤(Yann LeCun) 외 | 가중치 공유 기반 CNN으로 우편물의 손글씨 우편번호 인식 성공 |
| 1998 | LeNet-5 | 7개 층, 32×32 크기 숫자 이미지 분류, 미국 은행에서 수표의 손글씨 숫자 인식에 상용 활용 |
